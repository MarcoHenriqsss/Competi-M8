Cadastro de Tarefas

Esse cadastro será utilizado nas rotinas de Agenda, Oportunidades, Orçamentos e Projetos por exemplo, dentro desse cadastro você conseguirá inserir informações referentes a Tarefas que necessitam ser executadas.

Projeto > MOVIMENTO > TAREFAS > Lista Cadastro de Tarefas
CRM > MOVIMENTO > TAREFAS > Lista Cadastro de Tarefas

Inclusão de uma nova Tarefa

Para incluir uma nova Tarefa clique na opção no canto superior esquerdo. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

Cabeçalho

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Tipo Tarefa: Tipo de Tarefa que será realizada.
  • Título: Nome da Tarefa que será realizada.
  • Tipo Atividade: Tipo de Atividade que será realizada na Tarefa
  • Exemplo: Atividade externa, atividade interna, visita a cliente.
  • Status Tarefa: Status em que a Tarefa se encontra no momento, essa tela permite que sejam utilizados status personalizados.
  • Categoria: Tipo de Categoria da Tarefa.
  • Status: Utiliza-se o status "Pendente" para Tarefas não concluídas e "Finalizada" para Tarefas que foram finalizadas.
  • Descrição: Descrição do que será realizado na Tarefa.
  • Prioridade: A prioridade das Tarefas podem ser definidas entre "Baixa", "Media" e "Alta".
  • Complexidade: Nível de complexidade para desenvolver a Tarefa.
  • Pessoa: Pessoa para quem a Tarefa será executada.
  • Projeto: Caso precise vincular essa tarefa a algum Projeto, poderá fazer por esse campo.
  • Orçamento: Caso precise vincular essa tarefa a algum Orçamento, poderá fazer por esse campo.
  • Horas Estimadas: Horas Estimadas para a execução da Tarefa.
  • Centro de Custo: Centro de Custo ao qual serão vinculados os custos dessa Tarefa.
  • Ticket: Campo alfanumérico, utilizado para controle de chamados internos que originaram a demanda da tarefa.
  • Documentação: Campo de descrição livre para documentações técnicas sobre a tarefa, geralmente utilizada para descrever a resolução da mesma.

  • Data: Data em que a Tarefa foi gerada.
  • Hora: Hora em que a tarefa foi gerada.
  • Início Estimado Data: Data estimada para o inicio da execução da Tarefa.
  • Início Estimado Hora: Hora estimada para o início da execução da Tarefa.
  • Término Estimado Data: Data estimada para o término da Tarefa.
  • Término Estimado Hora: Hora estimada para o término da Tarefa.
  • Esforço Estimado (Horas/Minutos): Tempo estimado para a execução da Tarefa, será calculado automaticamente pelo sistema com base na data e horário informado para início e termino da tarefa.
  • Data Limite: Data Limite para o término da Tarefa.
  • Hora Limite: Hora Limite para o término da Tarefa.
  • Story Points: Unidade de medida para mensurar a complexidade de uma tarefa (usado em metodologias ágeis).
  • Cor: Você poderá definir uma cor para essa tarefa, utilizado como um facilitador de identificação nas listas de tarefas e agenda por exemplo.
  • Lembrete: Indica qual a periodicidade que será realizado o envio de lembretes sobre a Tarefa, sendo as opções nenhum, customizado, dia, três dias, cinco dias, semana, quinze dias, mês.
  • Data Lembrete: Quando utilizada a opção "Customizado" no campo Lembrete será habilitada esta opção para indicar a data do envio do lembrete sobre a Tarefa.
  • Hora Lembrete: Quando utilizada a opção "Customizado" no campo Lembrete será habilitada esta opção para indicar a hora do envio do lembrete sobre a Tarefa.
  • Responsável: Responsável pela execução da Tarefa.
  • Participantes: Participantes na execução da Tarefa.
  • Criador: Usuário criador da Tarefa.
  • Vínculo: Anteriormente utilizado para vinculo de outras tarefas, hoje o sistema faz esse processo de forma otimizada na aba Tarefas Vinculadas.

Após preencher os campos necessários, clique em para que o item seja lançado na listagem, dessa forma você poderá lançar um novo item, assim como editá-los.

Timeline

Nesta aba serão listadas alterações e comentários realizados na Tarefa.

Comentários

  • Comentário: Campo descritivo onde você poderá informar algum comentário sobre a Tarefa.

Após inserir o comentário, clique em para que o item seja mostrado na aba Timeline, dessa forma você poderá lançar uma novo comentário.

Anexos

A aba Anexos permitirá que você anexe imagens ou arquivos, estes ficarão vinculados a esta Tarefa. O anexo poderá ser feito a partir da leitura do QR-Code, ou anexo direto de arquivos.

  • Código: Código interno gerado automaticamente pelo sistema.
  • Fotos pelo Celular: Através da leitura do QR-Code com um Smartphone, o sistema direciona o usuário para um link com essa Tarefa, onde todos os arquivos e imagens que o usuário incluir por esse link irão aparecer na grid de anexos do Cadastro.
  • Descrição: Campo onde será informado nome para identificação do anexo.
  • Arquivo: Campo onde será possível selecionar o arquivo desejado.

Após preencher os campos, clique em para que o item seja lançado na listagem abaixo, dessa forma você poderá lançar um novo item, assim como editá-lo.

Tarefas Vinculadas

  • Tarefa: Código da Tarefa que deseja vincular.
  • Descrição: Descrição do vinculo entre as Tarefas.

Após preencher os campos, clique em para que o item seja lançado na listagem abaixo, dessa forma você poderá lançar um novo item, assim como editá-lo.

Ações

  • Duplicar: Esta rotina duplicará a Tarefa, com um novo código de registro.
  • Reagendar: Está rotina irá alterar os campos "Data" e 'Hora", do cabeçalho da Tarefa.

Edição de Tarefas

Ao acessar a tela, você conseguirá listar todas as Tarefas ou filtrá-las de acordo com os filtros disponíveis na tela, para editá-las clique no botão Editar.

Exclusão de Tarefas

Você também conseguirá fazer a exclusão de uma Tarefa clicando em Excluir. Ao excluir essa Tarefa você não conseguirá recuperá-la e também não poderá utilizá-la em nenhuma rotina do sistema.
