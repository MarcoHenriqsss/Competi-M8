Integração RD Station

Atualmente, a integração entre o sistema e o RD Station permite a captura automática de leads, otimizando o processo de entrada de contatos qualificados no CRM. Neste artigo, explicamos como configurar essa integração e como realizar a importação dos leads diretamente para o sistema.

Para iniciar o processo de integração, é necessário possuir o Token de API do RD Station. Esse token é fundamental para que o sistema consiga se comunicar com a plataforma RD Station.

  • Caso ainda não possua esse token, entre em contato com o suporte do RD Station e solicite a chave de integração.
Configurações > CADASTROS > CADASTROS > Lista Cadastro de Estabelecimentos

Configuração Integração CRM

Ao acessar essa tela, preenche com o Token do RD Station e clique em salvar.

Após preenchimento do Token, os próximos passos são entrar no cadastro da conta e importar os Leads. Segue caminho:

CRM > MOVIMENTO > CONTAS > Lista Cadastro de Contas

Em cadastro de Contas, ao clicar no botão "Ações", selecione a opção "Importar Lead RD Station". Ao realizar essa ação, o sistema importará o lead e criará automaticamente um novo cadastro de conta correspondente no módulo CRM.

Os dados que serão importados pelo sistema, caso estejam preenchidos no RD Station, incluem: Razão Social/Nome Fantasia, CEP, Logradouro, Número, Município, Bairro, Telefone e E-mail.
