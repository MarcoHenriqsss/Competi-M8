Exportar CT-e

Este processo tem como objetivo exportar lançamentos de CT-e, emitidos pelo Sistema.

CTe > MOVIMENTO > UTILITÁRIOS > Exportar CT-e

Filtros

  • Emissão Inicial: Campo disponível para fazer a pesquisa dos lançamentos, através da data de emissão, podendo informar uma data específica ou um período que deseja fazer a pesquisa.
  • Documento inicial: Campo disponível para fazer a pesquisa dos lançamentos pelo número de documento, podendo informar um específico, ou intervalo de numerações de documento.
  • Empresa: Neste campo informe a empresa pelo qual deseja fazer a pesquisa dos lançamentos.
  • Pessoa: Neste campo informe a pessoa pelo qual deseja fazer a pesquisa dos lançamentos.
  • Estabelecimento: Neste campo informe o estabelecimento pelo qual deseja fazer a pesquisa dos lançamentos.
  • Chave CT-e: Campo disponível para especificar a chave de acesso para pesquisar o CT-e.
  • Condição de Pagamento: Neste campo informe a condição de pagamento pelo qual deseja fazer a pesquisa dos lançamentos.
  • Nome Arquivo CT-e: Espaço disponível para seleção do nome do arquivo que será exportado, podendo ser Chave, Protocolo ou Número Documento.
  • Nome Arquivo CT-e Cancelada: Espaço disponível para seleção do nome do arquivo que será exportado para os documentos que estão com o status "Cancelado", podendo ser Chave, Protocolo ou Número Documento.

Para pesquisar os lançamentos de CT-e, basta clicar em. Após pesquisar, basta selecionar os documentos desejados e clicar em, com isso será criado em sua máquina uma pasta com arquivo XML de todos os documentos selecionados.
