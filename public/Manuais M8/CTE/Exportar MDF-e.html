Exportar MDF-e

Este processo tem como objetivo exportar lançamentos de MDF-e, emitidos pelo Sistema.

CTe > MOVIMENTO > UTILITÁRIOS > Exportar MDF-e

Filtros

  • Emissão Inicial: Campo disponível para fazer a pesquisa dos lançamentos, através da data de emissão, podendo informar uma data específica ou um período que deseja fazer a pesquisa.
  • Documento inicial: Campo disponível para fazer a pesquisa dos lançamentos pelo número de documento, podendo informar um específico, ou intervalo de numerações de documento.
  • Estabelecimento: Neste campo informe o estabelecimento pelo qual deseja fazer a pesquisa dos lançamentos.
  • Chave MDF-e: Campo disponível para especificar a chave de acesso para pesquisar o MDF-e.
  • Nome Arquivo MDF-e: Espaço disponível para seleção do nome do arquivo que será exportado, podendo ser Chave, Protocolo ou Número Documento.
  • Exportar PDF: Ao marcar, será exportado também o PDF do documento.

Para pesquisar os lançamentos de MDF-e, basta clicar em. Após pesquisar, basta selecionar os documentos desejados e clicar em, com isso será criado em sua máquina uma pasta com arquivo XML de todos os documentos selecionados.
