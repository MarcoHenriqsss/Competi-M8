Análise Sugestão de Compra

Nessa rotina, poderá gerar uma Análise de Sugestão de Compra de forma prática e rápida de Saldo dos produtos cadastrados no sistema, essa análise é feita com base no saldo dos itens de todos os Almoxarifados quantidade vendida de cada produto em determinado período.

Compras > MOVIMENTO > ANÁLISE > Análise Sugestão de Compra

Filtros

  • Calcular Com Base: Campo que permite escolher como a sugestão será calculada, podendo ser com base em "Dias" ou "Período".
    • Dias: Quando a opção "Dias" é selecionada, aparecerá o campo "Calcular com base nos últimos (dias)" no qual você deve inserir a quantidade de dias desejada.
      • Exemplo: 120 dias.
    • Período: Ao escolher a opção "Período", você deverá preencher o campo "Período" com um itervalo de datas que será considerada para a Sugestão.
      • Exemplo: 01/09/2023 a 26/09/2023.

  • Estoque para (dias): Campo onde você informará para quantos dias futuros deseja calcular o estoque a ser comprado.
  • Estabelecimento Gerar: Campo para indicar em qual estabelecimento será gerada a Solicitação de Compra, Solicitação de Transferência e Ordem de Compra.
  • Estabelecimento Filtrar: Campo para informar o estabelecimento que será usado para filtrar os dados na Sugestão de Solicitação/Ordem de Compra.
  • Fornecedor: Campo para filtrar um fornecedor específico, será considerado fornecedor vinculado ao cadastro no produto.
  • Família: Campo onde você poderá filtrar os produtos por família.
  • Grupo Estoque: Campo onde você poderá filtrar os produtos por seu Grupo de Estoque.
  • Marca: Campo onde você poderá filtrar os produtos por sua Marca.
  • Produto: Campo de seleção múltipla para informar um ou mais produtos que deseja filtrar.
  • Código Identificação Interno: Campo para filtrar os produtos pelo código interno deles.
  • Ocultar Itens Sem Sugestão: Permite escolher se deseja ocultar ou não os itens que não possuem sugestão de compra.
  • Considerar Requisição Estoque: Campo que permite considerar as requisições processadas e/ou pendentes para os itens filtrados. Essas requisições serão tratadas como "Saídas" e influenciarão o cálculo das compras.
  • Considerar Estoque Mínimo: Campo que permite considerar o estoque mínimo na Sugestão de Compra.
  • Considerar Pedidos Pendentes: Campo que considerar os pedidos pendentes, como reserva de estoque.
  • Considerar Orçamento CRM: Campo que permite considerar a reserva de estoque dos produtos alocados em Orçamentos (CRM).
  • Considerar OS Pendentes: Campo que permite considerar a reserva de estoque dos produtos alocados em Ordens de Serviço pendentes.
  • Considerar OC Pendentes: Campo que permite considerar produtos alocados em Ordens de Compra pendentes.
  • Considerar OP Pendentes: Campo que permite considerar produtos alocados em Ordem de Produção pendentes.
  • Filtrar Datas Lançamentos Pendentes: Campo que permite filtrar ou não os lançamentos pendentes (Pedidos, Ordens de Compra, Ordens de Serviço) para gerar a Sugestão de Compra.
  • Listar sem Vendas: Opção que permite escolher listar ou não os itens que não têm vendas registradas no momento em que a sugestão é gerada.

Para realizar a pesquisa da sugestão, após preencher os filtros desejados acima, basta clicar em.

Ao realizar a pesquisa, serão listados abaixo os itens conforme filtros informados, com a sutgestão de compra calculada pelo sistema com base nas últimas movimentações destes produtos.

Na listagem em questão, você pode facilmente verificar a quantidade de saída de um produto na coluna "Saída" e avaliar o estoque atual, considerando as colunas "Estoque" e "Est. Atual (Disp)". Com base nessas informações, o sistema realiza o cálculo da Sugestão de Compra, que pode ser encontrada nas colunas "Sug Compra" e "Sug Compra 2". É importante destacar que as quantidades sugeridas para compra são editáveis pelo usuário, oferecendo flexibilidade total no processo de tomada de decisão.

O processo de Sugestão de Compra inclui um recurso facilitador que permite a geração de Solicitações de Compra ou Ordens de Compra a partir dela. Para acessar essa funcionalidade, disponibilizamos dois botões de ação: "Gerar Solicitação de Compra" e "Gerar Ordem de Compra"
