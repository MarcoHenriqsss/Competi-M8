Cadastro de Tipo de Ordem de Compra

O Tipo de Ordem de Compra é um cadastro que permite a parametrização dos lançamentos de Ordem de Compra no sistema.

Compras > CADASTROS > CADASTROS > Lista Tipo de Ordem Compra

Inclusão de Tipo de Ordem de Compra

Para incluir um novo cadastro de Tipo de Ordem de Compra, clique na opção no canto superior esquerdo.

Cabeçalho

  • Código: Código sequencial de identificação, gerado automaticamente pelo sistema.
  • Nome: Neste campo você definirá um nome para o registro de Tipo de Ordem de Compra.
  • Tipo Alçada: Tipo de alçada que será respeitado quando com relação a aprovação das Ordens de Compra lançadas com esse Tipo.
  • Usar Checklist: Quando marcado, será considerado o check list para aprovação das Ordens de Compra, lançados com esse Tipo.
  • Observações: Campo de descrição livre para informações adicionais referente a este cadastro.

Após preenchidos os campos, clique em para que o item seja lançado na listagem abaixo.

Edição de Tipo de Ordem de Compra

Ao acessar a tela, você conseguirá listar todos os cadastros de Tipos de Ordens de Compra ou filtrá-los de acordo com os filtros disponíveis na tela, para editá-los clique no botão Editar.

Exclusão de Tipo de Ordem de Compra

Você também conseguirá fazer a exclusão de um Tipo de Ordem de Compra, clicando em Excluir. Caso necessário poderá restaurar o registro excluído, clicando em Restaurar Registro, na lista de Tipo de Ordem de Compra, lembrando que essa opção está disponível apenas para usuários configurados como Administradores.
