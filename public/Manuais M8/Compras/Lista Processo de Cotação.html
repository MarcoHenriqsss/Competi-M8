Lista Processo de Cotação

Lista de Processo de Cotação de Compra é o processo posterior do Envio de Cotação, onde será possível acompanhar a Cotação até o(s) Fornecedor(es) aceitarem ou recusarem a proposta.

Compras > MOVIMENTO > COTAÇÕES > Lista Processos de Cotações

Consulta de Processos de Cotação

Para visualizar a lista de Processo de Cotações de Compra, basta clicar no ícone de pesquisa, conforme mostra a imagem abaixo e todas as Cotações serão listadas, agrupadas pelo Estabelecimento que as mesmas pertencem. Para visualizar a Cotação, clique em. Nesta tela você poderá visualizar as Solicitações de Compra selecionas para gerar a Cotação, os dados do Processo de Cotação, assim como uma sugestão de melhor escolha para efetivar a compra.

Ações

  • Gerar Ordem de Compra: Essa opção deverá ser utilizada para gerar uma Ordem de Compra a partir deste processo de Cotação de acordo com os itens selecionados.
  • Prorrogar Cotação: Será possível alterar o prazo caso necessário, dessa forma será habilitado um campo onde você informará a data que deseja prorrogar a cotação.
  • Reenviar Processo Cotação - Itens Pendentes: Essa ação poderá ser utilizada quando algum item da Cotação atual não possuir valor cotado pelo fornecedor, dessa forma poderá reenviar a cotação para o Fornecedor, esse processo somente será possível caso tenha itens pendentes.
  • Incluir Fornecedor: Poderá incluir fornecedor no Processo de cotação, ao clicar será exibida a tela do processo para selecionar o Fornecedor desejado, deverá clicar em Continuar, informar um contato, Tipo
  • Compra, em seguida deverá confirmar, o próximo passo deverá enviar a cotação, dessa forma adicionando um novo Fornecedor ao Processo de Cotação.

  • Cancelar: Utilize essa opção para cancelar o Processo de Cotação.
