Cadastro Regra

A singularidade desta funcionalidade está na sua capacidade de registrar regras personalizadas para aplicação em Notas Fiscais, proporcionando uma abordagem minuciosa e específica para cada cenário. Isso vai além das informações convencionais. Esta abordagem personalizada assegura uma adaptação precisa e detalhada às exigências particulares de cada situação, conferindo flexibilidade e controle aos usuários. A incorporação sistemática das regras selecionadas nas Notas Fiscais simplifica e otimiza o processo, garantindo consistência e conformidade.

Configurações > CADASTROS > CADASTROS > Lista Regras de Cálculo

Inclusão de Cadastro Regra

Para adicionar uma nova Regra clique em no canto superior esquerdo da tela.

Cabeçalho

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Tipo Retorno: Neste campo ira definir se a expressão vai ser utilizada no formato de texto ou se em formato de numero/calculo numérico
    • Numero: Deverá marcar essa opção para utilização da regra como calculo, de custo operação ou custo gerencial por exemplo.
    • Texto: Essa opção deverá ser marcada quando a regra que está configurando será de texto para observação de Notas Fiscais.
  • Limpar Texto: Essa opção será exibidando marcada opção Texto no campo Tipo Retorno, citado acima, quando marcado irá limpar texto atual (dados que já estão salvos) ao processar regra.

Limpar Texto: Essa opção será exibidando marcada opção Texto no campo Tipo Retorno, citado acima, quando marcado irá limpar texto atual (dados que já estão salvos) ao processar

  • Nome: Nesse campo você deverá informar um nome de identificação desta Regra.
  • Expressão: Aqui será onde irá definir oque ira ser validado como expressão, o que será utilizado para o calculo, aliquota, valor ou informação que precisa.

Para facilitar no processo da criação de Regras, disponibilizamos algumas teclas de Atalho:

  • "d": para campos do documento fiscal (Como por exemplo ValorAcrescimo, ValorDesconto, TotalProdutosDocumento, TotalDocumento, dentre outros )
  • "i": para campos do itens do documento (Como por exemplo ProdutoId, PercentualDescontoItem, AliquotaIcmsItem, ValorIpiItem, dentre outros )
  • "f": campos de configuração impostos estabelecimento (Como por exemplo AliquotaIrrfConfiguracaoImposto, AliquotaCofinsConfiguracaoImposto, AliquotaPisConfiguracaoImposto, dentre outros )
  • "k": para campos do cálculo peso (Como por exemplo Altura, Largura, PesoBruto, PesoLiquido, dentre outros )
  • "p": para campos do produto (Como por exemplo ValorUltimaCompra, LucroEstimadoAlocadoProduto, DespesasFixasCategoriaProduto, dentre outros )
  • "s": para campos do cálculo sugestão compra (Como por exemplo EstoqueDisponivel, Estoque, EstoqueDias, dentre outros )
  • "o": para operadores (Como por exemplo +, -, *, /, dentre outros)

Edição de Cadastro Regra

Ao acessar a tela, você conseguirá listar todas as Regras de calculo ou filtrá-las de acordo com os filtros disponíveis na tela, para editá-los clique no botão Editar.

Exclusão de Cadastro Regra

Você também conseguirá fazer a exclusão de uma Regra clicando em Excluir. Caso necessário poderá restaurar o registro excluído, clicando em Restaurar Registro, na lista Cadastro de Regra, lembrando que essa opção está disponível apenas para usuários configurados como Administradores.
