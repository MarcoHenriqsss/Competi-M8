Cadastro de CFOP

O CFOP - Código Fiscal de Operações e de Prestações é o código do sistema tributarista brasileiro, indicado nas emissões de notas fiscais, declarações, guias e escrituração de livros. Dependendo do tipo de CFOP, será fixada a tributação sobre a operação e haverá movimentações financeiras e de estoque de interesse do Fisco. Os diferentes tipos de CFOP separam as notas fiscais por tipo - entrada e saída, por região e por natureza da operação. É um código que contém quatro dígitos e cada um deles tem uma identificação específica. O primeiro número se refere ao tipo de operação (1 para dentro do estado e 2 para fora do estado) e os demais, à finalidade e o tipo de produto/serviço.

Configurações > CADASTROS > CADASTROS > Lista Cadastro de CFOPs

Inclusão de CFOP

Para incluir um novo Cadastro de CFOP clique na opção no canto superior esquerdo.

Cabeçalho

  • Descrição: Informará a descrição para identificação da CFOP
  • Descrição Resumida: Informe a descrição resumida para identificação da CFOP.
  • CFOP Dentro UF: Neste campo informará o CFOP para dentro do estado, iniciando com os dígitos 1 ou 5.
  • CFOP Fora UF: Neste campo informará o CFOP para fora do estado iniciando com os dígitos 2 ou 6.
    • Para entradas de Notas de Importação, o grupo de CFOP será 3.000, onde o código inicia com o dígito 3.
  • Para emissão de Notas de Exportação, o grupo de CFOP será 7.000, onde o código inicia com o dígito 7.
  • Finalidade: Neste campo informará a natureza do CFOP:
    • Outra: São definidos para CFOPs de vendas, compras, remessas, etc.
    • Devolução: São definidos para CFOPs de devoluções e retornos.
    • Transferência: São definidos para CFOPs de transferências.

Edição de Cadastro de CFOP

Ao acessar a tela, você conseguirá listar todos os CFOPs cadastrados ou filtrá-los conforme os filtros disponíveis na tela, para editá-las clique no botão Editar.

Exclusão de Cadastro de CFOP

Você também conseguirá fazer a exclusão de um Cadastro de CFOP, clicado em Excluir. Ao excluir esse Cadastro de CFOP, não conseguirá recuperá-lo e também não poderá utilizá-lo em nenhuma rotina do sistema.
