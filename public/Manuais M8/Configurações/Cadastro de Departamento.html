Cadastro de Departamento

Neste cadastro você poderá parametrizar e agrupar os funcionários de sua empresa por Departamentos, de acordo com a organização interna da sua Empresa.

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Departamentos

Inclusão de Departamento

Para incluir um novo Cadastro de Departamento clique na opção no canto superior esquerdo.

Cabeçalho

  • Código: Código de identificação interna, gerado automaticamente pelo sistema para cada cadastro.
  • Nome: Neste campo, deverá informar um nome de identificação para este departamento.

Após preenchidos os campo, clique em para que o cadastrado seja registrado e assim será habilitada uma nova aba para configuração.

Usuários

Nesta aba deverá informar os usuários que fazem parte deste Departamento, este cadastro é utilizado também nas configurações de Alçadas no módulo Workflow, onde será definido uma hierarquia de aprovação de rotinas de compra, por exemplo, de acordo com os usuários de determinado Departamento.

  • Usuário: Informe o usuário desejado, poderá pesquisar por nome ou código do mesmo.

Após informado o usuário, clique em para que o cadastro seja lançado, depois disso poderá incluir novos usuários ou excluir os já existentes.

Edição de Cadastro de Departamento

Ao acessar a tela, você conseguirá listar todas os cadastros de Departamento ou filtrá-las de acordo com os filtros disponíveis na tela, para editá-los clique no botão Editar.

Exclusão de Cadastro de Departamento

Você também conseguirá fazer a exclusão de um Departamento, clicando em Excluir. Caso necessário poderá restaurar o registro excluído, clicando em Restaurar Registro, na lista de Departamentos, lembrando que essa opção está disponível apenas para usuários configurados como Administradores.
