Grupo de Acesso

Esse cadastro permitirá que sejam estabelecidas as liberações e bloqueios das rotinas do sistema para cada usuário.

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Grupos de Acesso

Inclusão de Grupo de Acesso

Cabeçalho

  • Código: Código sequencial de identificação do registro, gerado automaticamente pelo sistema.
  • Nome: Informe um nome para esse Grupo de Acesso.
  • Descrição: Você poderá informar uma descrição detalhada sobre esse Grupo de Acesso.

Depois de preenchidos os campo clique em para que sejam habilitadas novas para preenchimento.

Usuários

Nessa aba você deverá informar todos os usuários que farão parte de Grupo de Acesso, ou seja, as funcionalidades inseridas serão aplicadas para esses usuários.

  • Usuário: Informe o cadastro do usuário que deseja incluir nesse Grupo de Acesso.

Clique em para que esse usuário seja exibido na listagem abaixo, dessa forma poderá incluir novos cadastros.

Estabelecimentos

Nesta aba você deverá informar os Estabelecimentos que os usuário informadas na aba anterior terão acesso, dentro de cada um desses Estabelecimento serão habilitadas as funcionalidades inseridas nesse cadastro.

  • Estabelecimento: Informe o Estabelecimento desejado.

Clique em para que esse Estabelecimento seja exibido na listagem abaixo, dessa forma poderá incluir novos cadastros.

Funcionalidades

Nesta aba você selecionará todas as funcionalidades de liberação ou bloqueio que deseja aplicar ao acesso dos usuários informados anteriormente.

  • Código: Código sequencial de identificação do registro, gerado automaticamente pelo sistema.
  • Funcionalidade: Nesse campo você deverá pesquisar e selecionar a funcionalidade que deseja incluir ao Grupo de Acesso.
  • Controle Total: Quando marcado, os integrantes do Grupo terão acesso total a funcionalidade selecionada acima.
  • Leitura: Quando marcado, os integrantes do Grupo poderão apenas visualizar a rotina ou cadastro correspondente a funcionalidade selecionada acima.
  • Gravação: Quando marcado, os integrantes do Grupo poderão gerar um novo cadastro na rotina correspondente a funcionalidade selecionada acima.
  • Exclusão: Quando marcado, os integrantes do Grupo poderão fazer a exclusão dos cadastros correspondentes a funcionalidade selecionada acima.

Clique em para que essa Funcionalidade seja exibida na listagem abaixo, dessa forma poderá incluir novos cadastros. As Funcionalidades informadas poderão ser excluídas ou editadas conforme a necessidade da sua

empresa.

A forma mais utilizada para inserção de Funcionalidades no Grupo de Acesso é de, essa permite selecionar várias Funcionalidades de uma vez, assim como possibilita melhor visualização das opções disponíveis. Ao clicar será exibido na tela um modal onde você poderá filtrar as Funcionalidades por Módulo, Nome, Descrição e Funcionalidade.

Após filtradas as opções, selecione as desejadas clicando no checkbox na linha da mesma, também poderá selecionar todas as opções exibidas na tela.

Após selecionas as Funcionalidades desejadas basta clicar em uma das opções de Controle Total, Leitura, Gravação e Exclusão e seleciona se deseja permitir ou negar essa ação para as Funcionalidades.

Vale ressaltar que cada usuário poderá estar em mais de uma Grupo de Acesso, serão respeitadas as Funcionalidades de ambos os Grupos, porém não deverão ser informadas Funcionalidades contrárias, por exemplo, informar um bloqueio para determinada tela em um Grupo e a liberação total dessa mesma tela em outro Grupo.

Edição de Grupos de Acesso

Ao acessar a tela, você conseguirá listar todos os Grupos de Acesso cadastrados ou filtrá-los conforme os filtros disponíveis na tela, para editá-los clique no botão Editar

Exclusão de Grupos de Acesso

Você também conseguirá fazer a exclusão de um Grupo de Acesso clicado em Excluir. Ao excluir esse lançamento, você não conseguirá recuperá-lo e também não poderá utilizá-lo em nenhuma rotina do sistema.
