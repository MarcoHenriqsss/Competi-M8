Cadastro de Municípios

Nesse artigo será explicado o cadastro de Município. No M8 é possível cadastrar Municípios de acordo coma a necessidade da sua empresa, seja ele nacional ou estrangeiro.

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Municípios

Inclusão de Município

Para adicionar uma novo Município clique em. Para te auxiliar, nesse artigo descreveremos a descrição de cada um dos campos da tela.

Cabeçalho

  • Código: Código sequencial de identificação gerado automaticamente pelo sistema.
  • Estado: Deverá informar a qual estado o município pertence.
  • Comarca: Poderá informar a comarca desse município.
  • Município: Deverá informar o nome do Município.
  • CEP: Poderá informar o CEP (Código de Endereçamento Postal) do Município em questão.
  • Estrangeira: Essa informação deverá constar como SIM em casos em que o município for estrangeiro.
  • IBGE: Poderá informar o código IBGE deste município.
  • SIAFI/CFPS: Poderá informar o código SIAFI/CFPS deste município.
  • Código Tributação NFS-e: Poderá informar o código de tributação para emissão de NFS-e (código informado pela prefeitura).
  • Código Estadual: Poderá informar o código estadual qual esse município pertence.
  • % ISS: Poderá informar a % ISS (Imposto sobre serviços) que será aplicado sobre prestação de serviço para esse município.

Edição Cadastro de Município

Ao acessar a tela, você conseguirá listar todas os Municípios ou filtrá-los de acordo com os filtros disponíveis na tela, para editá-los clique no botão Editar.

Exclusão Cadastro de Município

Você também conseguirá fazer a exclusão de um Município clicando em Excluir. Caso necessário poderá restaurar o registro excluído, clicando em Restaurar Registro, na lista Cadastro de Municípios, lembrando que essa opção está disponível apenas para usuários configurados como Administradores.
