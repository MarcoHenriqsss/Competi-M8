Configurar Pessoas

A rotina de Configurar Pessoas, funciona como um facilitador ao usuário, transformando um cliente em Fornecedor, Vendedor, Transportador.. de uma única vez. Quando selecionadas as funções que essa pessoa terá no sistema, será habilitado esse cadastro nas telas determinadas mantendo o mesmo código de lançamento.

Configurações > MOVIMENTO > CONFIGURAÇÕES > Configurar Pessoas

Classificação de Pessoas

  • Pesquisa: Informe a pessoa que deseja configurar, você pode pesquisar por nome, razão social, cnpj ou cpf, como preferir.
  • Cliente: Marque para que a pessoa informada seja configurada também como cliente, para utilização em rotinas de venda por exemplo. Esse cadastro será exibido na Lista Cadastro de Cliente com mesmo código do cadastro original.
  • Fornecedor: Marque essa opção para que a pessoa informada seja configurada também como fornecedor, para utilização nas rotinas de compra. Esse cadastro será exibido na Lista de Cadastro de Fornecedores com mesmo código do cadastro original.
  • Funcionário: Marque essa opção para que a pessoa informada seja configurada também como funcionário. Esse cadastro será exibido na Lista de Cadastro de Funcionários com o mesmo código do cadastro original.
  • Transportador: Marque essa opção para que a pessoa informada seja configurada também como transportador, para utilização nas rotinas de faturamento ou emissão de CT-e por exemplo. Esse cadastro será exibido na Lista de Cadastro de Transportadoras com mesmo código do cadastro original.
  • Vendedor: Marque essa opção para que a pessoa informada seja configurada também como vendedor, para utilização nas rotinas de faturamento ou calculo de comissões por exemplo. Esse cadastro será exibido na Lista de Cadastro de Vendedores com mesmo código do cadastro original.
  • Motorista: Marque essa opção para que a pessoa informada seja configurada também como motorista, para utilização nas rotinas de faturamento ou emissão de CT-e ou MDF-e por exemplo. Esse cadastro será exibido na Lista de Cadastro de Motoristas com mesmo código do cadastro original.
  • Contador: Marque essa opção para que a pessoa informada seja configurada também como contador, para utilização como contador responsável da sua empresa ou como contato responsável pelo recebimento do XML das notas fiscais dentro do cadastro do cliente por exemplo. Esse cadastro será exibido na Lista de Cadastro de Contadores com mesmo código do cadastro original.
  • Conta (CRM): Marque essa opção para que a pessoa informada seja configurada também como Conta CRM, para utilização em orçamentos do módulo CRM ou cadastro de oportunidades por exemplo. Esse cadastro será exibido na Lista de Cadastro de Contas com mesmo código do cadastro original.
  • Cliente Consumidor Final: Opção válida para cadastro de cliente, quando marcada, não poderão ser feitas alterações no cadastro do cliente, para liberação dos campos precisa ser desmarcada essa opção.
  • Valor Unitário: Essa opção definirá de onde o sistema buscará a informação do valor unitário dos produtos e serviços informados nas rotinas de faturamento, sendo as opções:
    • Preço de Venda: Será exibido como valor unitário o valor informado no cadastro do produto ou serviço no campo Preço de Venda.
    • Preço Última Compra: Será exibido como valor unitário o valor da último compra dessa produto ou serviço.
    • Custo Médio: Será exibido como valor unitário o custo médio desse produto ou serviço.
    • Custo Médio Gerencial: Será exibido como valor unitário o custo médio gerencial desse produto ou serviço.

O valor unitário poderá ser alterado no lançamento da nota fiscal ou pedido por exemplo caso necessário.
