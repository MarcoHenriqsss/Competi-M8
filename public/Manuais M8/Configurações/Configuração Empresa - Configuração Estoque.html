Configuração Empresa - Configuração Estoque

Nesta aba da Configuração de Empresa, serão parametrizadas algunas configurações referente ao controle de estoque dos produto, como método de calculo de custo médio, validações de quantidade de estoque disponível, entre outros pontos importantes.

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Empresas

Configuração Estoque

  • Regra Sugestão Compra: Neste campo poderá ser vinculada uma regra para calculo para coluna Sug. Compra na tela Consulta Sugestão de Compra, quando não informado o sistema considera uma calculo padrão para sugerir a quantidade a ser comprada.
  • Alterar Custo Unitário: Definirá se poderá ou não ser alterado o campo Custo Unitário ao lançar Itens em uma Requisição de Estoque.
  • Método Custo Médio: Definirá se o Custo Médio será calculado a cada documento lançado ou mensalmente.
  • Custo Transf. Estoque: Definirá se os lançamentos de Transferência de Estoque irão ou não calcular custo.
  • Validar Estoque: Configuração válida para Requisição de Estoque, quando marcado ao lançar um item na Requisição será validado se o mesmo possui estoque suficiente para tal movimentação.
  • Validar Saldo Custo Médio: Configuração válida para Requisições, quando marcado será mantido o custo médio anterior quando o saldo de estoque for menor ou igual a zero.
  • Custo Médio Requisição: Quando marcado, será calculado o custo médiot para o lançamento de Requisições de entrada.
  • Controlar Estoque Serviço: Definirá se será feito controle ou não das movimentações de serviços prestados e tomados.
  • Estoque Consulta Lote: Quando marcado, ao lançar um item em um Pedido de Venda Rápido, será exibido para pesquisa no campo Local de Estoque apenas o Lote que tenha saldo deste item.
  • Validar Item O.S.: Serão validados se os dados digitados na requisição de estoque correspondem a O.S que originou tal requisição.
  • Exibir Data Últ. Compra: Quando marcado, será exibida a data de última compra do produto ao pesquisá- lo nas telas Pedidos e Orçamentos.
  • Casas Decimais Qtde.: Poderá definir a quantidade de casas decimais permitidas para quantidade dos itens, nos lançamentos do módulo Estoque.
  • Casas Decimais Valor.: Poderá definir a quantidade de casas decimais permitidas para valor dos itens, nos lançamentos do módulo Estoque.
