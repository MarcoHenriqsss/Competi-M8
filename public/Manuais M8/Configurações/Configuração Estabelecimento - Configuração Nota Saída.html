Configuração Estabelecimento - Configuração Nota Saída

Nesta rotina, você será capaz de estabelecer padrões exclusivos para uso em documentos fiscais, como a quantidade de casas decimais para o valor unitário e a quantidade, a série padrão para a emissão dos documentos, entre outros.

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Estabelecimentos

  • Código: Código de identificação do registro da Configuração Nota Saída.
  • Gerar Financeiro: Ao marcar esta opção, o sistema irá gerar automaticamente um ou mais lançamentos de Contas a Receber do respectivo Documento Fiscal no momento do faturamento.
  • Solicitar Faturar Separado: Quando marcado, será solicitado ao usuário se o mesmo deseja fazer o faturamento separado para os produtos e serviços para o Pedido Rápido.
  • Faturar Produto Separado NF: Ao marcar esta opção, quando gerada uma Nota Fiscal a partir de uma Ordem de Serviço, se houver tanto produtos quanto serviços nesta Ordem, o sistema automaticamente irá gerar dois Documentos Fiscais distintos, um com os Produto e outro com os Serviços.
  • Faturar Produto Separado Simples Fatura: Ao marcar esta opção, quando gerada uma Nota Fiscal a partir de uma Ordem de Serviço e houver tanto produtos quanto serviços nesta Ordem, o sistema automaticamente irá gerar duas Simples Faturas separadas, uma com os Produtos e outra com os Serviços.
  • Atualizar Custo Margem: Quando marcado, será atualizado o custo nos itens para os Pedido, Ordens de Serviço e Orçamentos.
  • Serie: Campo disponível para configuração da Série padrão para emissão dos Documentos Fiscais.
  • Serie de Serviço: Campo disponível para configuração da Série padrão dos Documentos Fiscais de Serviço.
  • Série de Simples Fatura: Campo disponível para configuração da Série padrão para lançamentos de Simples Fatura.
  • Casas decimais Quantidade: Opção onde você poderá padronizar a quantidade de casas decimais permitas para a quantidade de cada produto ou serviço lançado no Documento Fiscal.
  • Casas decimais Valor Unitário: Opção onde você poderá padronizar a quantidade de casas decimais permitas para o valor unitário de cada produto ou serviço lançado no Documento Fiscal.
