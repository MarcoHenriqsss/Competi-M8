Configurações do Sistema

Nesta rotina você conseguirá definir padronizações para uso do sistema como formato do texto, local de estoque padrão.

Configurações > MOVIMENTO > CONFIGURAÇÕES > Configurações do Sistema

  • Local Estoque Padrão: Neste campo poderá definir um Local de Estoque padrão para as movimentações de estoque do sistema.
  • Formato Letras: Neste campo você poderá definir o formato de letras do sistema, sendo as opções livre, maiúscula, minúsculas, somente a primeira maiscúla.
  • Cadastro Automático Empresas: Quando marcado, os cadastros de Pessoas e Produtos serão vinculados automáticamente a todas as empresas configurados no sistema.
  • Desbloqueio Automático: Quando marcado, serão desbloqueados automaticamente os cadastros e Produtos e Pessoas quando salvo o cadastro.
  • Pasta/Diretório Anexos: Informe o caminho da pasta que deseja que sejam salvos os arquivos baixados pelo sistema.
  • Gravar Log de Eventos: Quando marcado, será gravado o log de cadastro nas rotinas do sistema.
  • Gravar Log de Alteração de Dados: Quando marcado, será gravado de alteração dos cadastros e rotinas do sistema.
  • Exibir Menu sem Permissão: Definirá se será exibido ou não menu, mesmo que o usuário não tenha permissão aquela determinada rotina.
  • Obrigatório Classificação Cliente/Conta CRM: Quando marcado, se tornará obrigatório preencher o campo Classificação no Cadastro de Cliente e Conta CRM.
  • Obrigatório Ramo Atividade Cliente: Quando marcado será obrigatório preencher o campo Ramo de Atividade no Cadastro de Cliente.
  • Obrigatório Portador Cliente: Quando marcado o campo Portador se tornará obrigatório no Cadastro de Cliente.
  • Obrigatório Sitação Crédito Cliente: Quando marcado, o campo Situação de Crédito se tornará obrigatório no Cadastro de Cliente.
  • Obrigatório Operação Fiscal por Empresas: Quando marcado, permitirá atribuir configurações específicas para empresas diferentes.
  • Valor Estoque Item Ordem de Produção: Quando marcado, será feita validação de estoque ao lançar itens apontados na Ordem de Produção, quando desmarcado, essa validação será feita ao Encerrar a Ordem de
  • Produção.
  • Produto: Utilize essa opção para habilitar o cadastro automático de produtos em todas as empresas configuradas no sistema, logo fazendo o cadastro em uma, ele será replicado para as demais.
  • Cliente: Utilize essa opção para habilitar o cadastro automático de clientes em todas as empresas configuradas no sistema, logo fazendo o cadastro em uma, ele será replicado para as demais.
  • Fornecedor: Utilize essa opção para habilitar o cadastro automático de fornecedores em todas as empresas configuradas no sistema, logo fazendo o cadastro em uma, ele será replicado para as demais.
  • Obrigatório Ref. Fabricante: Quando marcado, o campo Ref. Fabricante se tornará obrigatório no Cadastro de Produto.
  • Validar Ref. Fabricante: Quando marcado, será validado se o código de referencia de fabricante informado já está vinculado a outro produto.

  • Validar Cód. Ident. Interno: Quando marcado, será validado se o código de identificação interna de fabricante informado já está vinculado a outro produto.
  • CNPJ Responsável Dados XML: Informe o CNPJ do responsável pelo XML das das Notas Fiscais e Conhecimentos de Transporte, dessa forma o mesmo poderá baixar esses arquivos.
  • Contato Responsável Dados XML: Informe contato da pessoa responsável pelo XML das Notas Fiscais e Conhecimentos de Transporte.
  • E-mail Responsárvel Dados XML: Informe o e-mail do responsável pelo XML das Notas Fiscais e Conhecimentos de Transporte.
  • Fone Responsável Dados XML: Informe o número de telefone do responsável pelo XML das Notas Fiscais e Conhecimentos de Transporte.

Após preenchidos os campos desejados, basta clicar em para habilitar as configurações feitas.
