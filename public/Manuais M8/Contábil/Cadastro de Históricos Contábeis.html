Cadastro de Históricos Contábeis

Os históricos contábeis são responsáveis por evidenciar (dar vida) os (aos) fatos contábeis, por isso devem ser claros, lógicos e precisos de tal forma que sua leitura forneça as informações que o usuário precisa.

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Históricos Contábeis
Contábil > CADASTROS > CADASTROS > Lista Cadastro de Históricos Contábeis

Inclusão de Cadastro de Históricos Contábeis

Para incluir um novo Histórico Contábil clique na opção no canto superior esquerdo. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos.

Cabeçalho

  • Código: Código de identificação sequencial gerado automaticamente pelo sistema.
  • Nome: Nesse campo você deverá inserir uma descrição livre ou utilizar variáveis para configurar o Histórico Contábil. Quando utilizadas as variáveis, o sistema buscará automaticamente as informações previamente configuradas no lançamento contábil, como o número do documento, nome do fornecedor ou cliente, entre outros dados que podem ser configurados atráves dessas variáveis.
  • Código Importação: Informado em casos em que os cadastros foram importados de outro sistema de gestão.
Para as variáveis, o Sistema possuí algumas teclas de atalho: "d" para campos regra do histórico, "b" para campos do cadastro de bens, "o" para operadores.

Edição de Cadastro de Históricos Contábeis

Ao acessar a tela, você conseguirá listar todas os Cadastros de Históricos Contábeis ou filtrá-los de acordo com os filtros disponíveis na tela, para editá-los clique no botão Editar. As alterações feitas serão válidas para os novos registros feitos utilizando esse histórico.

Exclusão de Cadastro de Históricos Contábeis

Você também conseguirá fazer a exclusão de um Cadastros de Histórico Contábil, clicado em Excluir. Ao excluir o cadastro você não conseguirá recuperá-lo e também não poderá utilizá-lo em nenhuma rotina do sistema.
