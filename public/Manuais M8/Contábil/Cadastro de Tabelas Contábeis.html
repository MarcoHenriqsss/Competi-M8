Cadastro de Tabelas Contábeis

A Tabela Contábil é responsável pela integração com a contabilidade dos lançamentos realizados nos demais módulos, os lançamentos de entrada, saída, provisões de impostos, retenções na fonte, entre outras situações.

Inclusão de Tabela Contábil

Para incluir uma nova Tabela Contábil clique na opção no canto superior esquerdo. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

Cabeçalho

  • Código: Preenchido de forma automática pelo Sistema, ao salvar.
  • Ativo: Definirá se a tabela está ativa ou inativa para uso nas rotinas do sistema.
  • Nome: Você poderá informar um nome que facilite a identificação dessa tabela contábil.
  • Forma de Totalização: Poderá escolher a forma de totalização entre:
    • Analítica: Usada para gravar a informação de forma individual.
    • Sintética: Usada para gravar a informação de forma acumulada. Sugerimos usar sempre a Forma Analítica.
      • Exemplo: ICMS mensal, várias Notas porém um único pagamento.

Exemplo: ICMS mensal, várias Notas porém um único pagamento.

Após preencher os campos, clique em, em seguida serão habilitadas outras abas do lado esquerdo da tela para preenchimento.

Contabilização

Nesta aba serão configuradas as regras da contabilização, com base nelas serão feitas as movimentações. Para cada ramificação da contabilização deverá ser informado um lançamento de Item Tabela Contábil.

  • Código: Preenchido de forma automática pelo Sistema, ao salvar.
  • Origem: Você deverá escolher entre:
    • 0 - Manual: Usado quando a Conta Contábil precisar ser informada de forma Manual.
    • 1 - Cliente: Deverá usar quando a origem for a conta Cliente.
    • 2 - Fornecedor: Deverá usar quando a origem for a conta Fornecedor.
    • 3 - Item Documento: Usado somente em Tabelas Contábeis vinculadas a Notas de Compra, quando usado o Débito Direto. O Sistema fará a busca no lançamento do Item da Nota.

    • 4 - Juros: Deverá usar quando a origem for a conta Juros.
    • 5 - Multa: Deverá usar quando a origem for a conta Multa.
    • 6 - Desconto: Deverá usar quando a origem for a conta Desconto.
    • 7 - Variação Cambial: Deverá usar quando a origem for a conta Variação Cambial.

Ações

  • Duplicar Tabela Contábil: Usado para duplicar a tabela contábil.
  • Replicar Empresa: Ao clicar, será aberto um modal para selecionar a empresa que deseja replicar. Gerando então um novo cadastro nessa empresa, com as mesmas configurações.
  • Testar Regra: Ao clicar, será validado o conteúdo informado no campo de regra Valor Lançamento, validando se há algo a ser ajustado ou não.

Edição de Tabela Contábil

Ao acessar a tela, você conseguirá listar todas as Tabelas Contábeis ou filtrá-las segundo os filtros disponíveis na tela, para editá-las clique no botão Editar. Vale ressaltar que após utilizada essa tabela contábil em alguma rotina, ao editar os lançamentos da aba Contabilização, os lançamentos anteriores não serão afetados, apenas os feitos desse momento em diante.

Atenção, NOME!!! Você está realizando alterações nas tabelas de contabilização do sistema. Essa alteração será válida para os lançamentos novos a partir dessa alteração. O Sistema não altera dados já processados anteriormente. Você realmente confirma a alteração????

Exclusão de Tabela Contábil

Você também conseguirá fazer a exclusão de uma Tabela Contábil, clicado em Excluir. Ao excluir a Tabela Contábil, você não conseguirá recuperá-la e também não poderá utilizá-la em nenhuma rotina do sistema.
