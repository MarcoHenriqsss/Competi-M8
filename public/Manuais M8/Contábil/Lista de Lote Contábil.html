Lista de Lote Contábil

O Lote Contábil é um lançamento que permite o usuário faça compensações contábeis para ajustar o saldo de contas.

Contábil > MOVIMENTO > MOVIMENTO > Lista Lotes

Inclusão de Lote

Para incluir um novo lançamento de Lote Contábil, clique na opção no canto superior esquerdo.

Cabeçalho

  • Código: Código sequencial de identificação, gerado automaticamente pelo sistema.
  • Status: Neste campo será exibido o status do lançamento, sendo Pendente, Aprovado, Processado, Encerrado ou Cancelado.
  • Estabelecimento: Estabelecimento para qual será gerado Lote.
  • Data: Data de lançamento das contabilizações geradas polo Lote.
  • Observações: Campo de descrição livre para informações adicionais.

Após preenchidos os campos acima, clique em para que as demais abas sejam disponibilizadas para preenchimento.

Itens

  • Código: Código sequencial de identificação, gerado automaticamente pelo sistema.
  • Natureza: Campo onde definirá se sua contabilização será de crédito ou um débito na conta informada.
  • Valor: Valor da contabilização que será gerar conforme a natureza.
  • Conta: Conta onde será gerado a contabilização conforme o valor e a natureza informados.
  • Histórico: Histórico referente a contabilização gerada através do lote.
  • Complemento: Campo de descrição livre para informações adicionais referente este lote.

Após preenchidos os campos, clique em para que o item seja lançado na listagem abaixo, depois você conseguirá editá-los e também lançar um novo item.

Contabilizações

Nessa aba ficarão armazenadas todas as contabilizações das contas informadas na aba de itens conforme o valor, natureza, conta e histórico informados.

Edição de Lote Contábil

Ao acessar a tela, você conseguirá listar todo o cadastros de Lotes Contábeis ou filtrá-los conforme os filtros disponíveis na tela, para editá-los clique no botão Editar.

Exclusão de Lote Contábil

Você também conseguirá fazer a exclusão de um Lote Contábil quando o mesmo estiver com status Pendente ou Cancelado, clicando em Excluir. Caso necessário poderá restaurar o registro excluído, clicando em Restaurar Registro, na lista de Lotes, lembrando que essa opção está disponível apenas para usuários configurados como Administradores.
