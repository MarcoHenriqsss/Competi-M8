Manutenção Contábil

Esta tela permite que sejam feitas alterações das Tabelas Contábeis utilizadas para contabilização de Notas Fiscais de Saída e Entrada.

Fiscal > MOVIMENTO > MANUTENÇÃO > Manutenção Contábil

Filtros

  • Movimento: Nesse campo você poderá escolher por filtrar as Notas de Entrada ou de Saída.
  • Data de: Estes campos permitem que você selecione um período que deseja filtrar as informações, tendo disponível um campo para data inicial e um segundo para data final do período, lembrando que, estas datas devem estar dentro do mesmo mês.
  • Documento de: Estes campo permitem que você filtre por um intervalo de números de documento, tendo disponível um campo para o documento inicial e um segundo para o documento final da faixa de documentos desejada.
  • CFOP: Este campo permitirá que você selecione uma CFOP para filtrar os documentos.
  • Operação Fiscal: Este último filtro permite que você filtre os documentos pela Operação Fiscal informada na NF.

Dados da Manutenção

  • Tabela Contábil: Neste campo você deverá preencher a Tabela Contábil que quer aplicar aos lançamento, ou seja, a tabela contábil que ficará vinculada a Nota Fiscal.

Como executar a Manutenção

Depois de informado os filtros desejados, clique em. Na listagem exibida abaixo dos filtros, você deverá selecionar todos os itens das Notas que você precisa alterar. Por fim, clique em, com base na tabela contábil informada nos Dados da Manutenção, será feita a atualização das contabilizações da NF.
