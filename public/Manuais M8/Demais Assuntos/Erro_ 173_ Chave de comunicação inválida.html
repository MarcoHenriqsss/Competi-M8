Erro: 173: Chave de comunicação inválida

Essa rejeição ocorre geralmente na emissão de Notas Fiscais de Serviço, ela é retornada pela prefeitura, geralmente indica que tem algum caractere especial lançado na NF.

Como resolver?

Observações NF

Para resolver, valide na NF se tem algum caractere especial lançado nas Observações da NF.

Observações Itens

Você também pode conferir nas Observações lançadas nos Serviços, essas informações também vão para a prefeitura

Cadastro do cliente

Outro campo que pode causar este erro é a Razão Social informada dentro do Cadastro do Cliente vinculado a Nota Fiscal, para validar entre no Cadastro do Cliente pelo atalho na NF, nesse Cadastro valide o campo Razão Social.

Alguns exemplo de carateres especiais são! @ # $ % & * ( ) - _ + = { } [ ]: ; " ' < > , .? / \ | ^ ~
