Notificação Estoque Mínimo

Este processo tem como objetivo auxiliar os usuários na identificação dos níveis de estoque quando estes se aproximam do mínimo. Em outras palavras, ele envia notificações por e-mail aos usuários responsáveis, desde que estejam devidamente.

Workflow > CADASTROS > NOTIFICAÇÕES > Configuração das Notificações.

Inclusão de Notificação

Para incluir uma nova Notificação clique na opção no canto superior esquerdo. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

Cabeçalho

  • Código: Código de identificação interna do registro de notificação.
  • Tipo: Tipo de envio de notificação.
    • Estoque Mínimo: Quando utilizado, irá disparar e-mails de notificação para os contatos do Cadastro de Estabelecimento que estiverem configurados com o tipo Compra ou Supervisor, com os produtos que estiverem com quantidade mínima de estoque.
  • Descrição: Descrição do registro de notificação.
  • Modelo Documento: Modelo de documento que será utilizado para enviar o e-mail.

Execução

  • Periodicidade: Periodicidade de envio das notificações.
    • Semanal: Quando utilizado, serão habilitados sete campos correspondentes a cada dia da semana, assim como o campo Hora Execução.
      • Hora Execução: Você deverá informar o horário de disparo do e-mail.
      • Dias da semana: Selecionará de acordo com os dias da semana que deseja que seja feito o envio dos e-mails, respeitando o horário informado no campo anterior.
    • Mensal: Quando utilizado, habilitará o campo Dia do Mês.
      • Hora Execução: Você deverá informar o horário de disparo do e-mail.
      • Dia do Mês: Informe o dia do mês que serão enviadas as notificações.

Inclusão de Modelo de Documento

Workflow > CADASTROS > CADASTROS > Lista Cadastro de Modelos de Documentos.

Nesta tela estará disponível a opção para definir o Modelo de e-mail para a notificação do estoque mínimo, onde você deverá selecionar o Tipo 61 - E-mail de Notificação Estoque Mínimo. Para personalizar o Modelo de Documento, temos à disposição as seguintes variáveis: Código do Estabelecimento, Razão Social do Estabelecimento e URL de Notificação de Estoque Mínimo.

Configuração Cadastro de Usuário

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Usuário

Dentro do Cadastro de Usuários você definirá quais usuários receberam os e-mails de Notificação de Estoque Mínimo, marcando a opção Notifica Estoque Mínimo.

Após a configuração das opções mencionadas acima, os usuários selecionados receberão as notificações por e- mail. Essas notificações incluirão um link que permitirá visualizar os produtos com estoques abaixo da quantidade mínima configurada.
Ao clicar no link associado ao nome do produto, os usuários terão acesso às informações sobre as últimas compras realizadas e as Ordens de Compras pendentes relacionadas ao produto em questão.

Clicando no nome do produto, será exibida uma nova tela com detalhamento deste item, assim como as últimos Notas de Compra lançadas no sistema e também Ordens de Compra pendentes para esse produto.
