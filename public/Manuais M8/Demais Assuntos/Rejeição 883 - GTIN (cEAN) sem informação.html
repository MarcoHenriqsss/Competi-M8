Rejeição 883 - GTIN (cEAN) sem informação

O que é a Rejeição 883 - GTIN (cEAN) sem informação?

Essa rejeição ocorre quando um ou mais itens lançados na Nota Fiscal não possuem código de barras informado, lembrando que a validação se aplica apenas para documentos de modelo 55 (NF-e). No M8, a rejeição é exibida conforme imagem abaixo no momento de transmissão ao SEFAZ.

Como resolver?

O primeiro passo é validar qual item está causando a rejeição, para isso entre na aba Produtos da Nota Fiscal.

Nessa tela você poderá verificar qual item está apresentando a rejeição de acordo com a coluna Código de Barras, pois a mesma estará sem informação para esse produto.

Caso a coluna não esteja sendo exibida, valide as configurações das colunas dessa grid.

Agora que já identificou qual item está sem o código de barras, edite o lançamento do mesmo na Nota e entre em seu cadastro pelo atalho (+). Dessa forma, você será redirecionado ao cadastro desse produto.

Dentro do cadastro do produto você poderá informar no campo Código de Barras o código de barras do mesmo, preencher a descrição "SEM GTIN", que é aceita pelo SEFAZ, ou clicar na opção, dessa forma o sistema criará automaticamente um código de barras para esse produto.

Depois disso, volte a aba Produtos da Nota Fiscal, atualize a grid dos produtos, verá que o campo que antes estava vazio na coluna Códigos Barras, agora está preenchido de acordo com a configuração do cadastro do produto.

Após fazer esse processo com todos os itens que estavam sem o código de barras, você poderá tentar transmitir a Nota Fiscal novamente em Ações > Faturar Documento.
