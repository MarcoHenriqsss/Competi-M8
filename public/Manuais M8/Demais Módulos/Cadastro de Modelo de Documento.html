Cadastro de Modelo de Documento

Nessa rotina você poderá criar modelos de envio de e-mail padronizados para rotinas específicas do sistema.

Workflow > CADASTROS > CADASTROS > Lista Cadastro de Modelos de Documentos

Inclusão de Modelo de Documento

Para incluir uma novo Modelo de Documento clique na opção no canto superior esquerdo. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

Cabeçalho

  • Código: Código de identificação interno do registro, será gerado automaticamente ao salvar.
  • Nome: Nome do registro de modelo de documento.
  • Tipo: Processo onde esse modelo de documento estará disponível para uso.
  • Modelo: Campo responsável pelo texto padrão que será enviado quando utilizado esse modelo.
  • Campos Disponíveis: Campos de variáveis disponíveis para utilização no campo Modelo, as opções serão exibidas de acordo com o tipo selecionado.

Edição de Modelo de Documento

Ao acessar a tela, você conseguirá listar todas os cadastros de Modelo de Documento ou filtrá-los de acordo com os filtros disponíveis na tela, para editá-los clique no botão Editar.

Exclusão de Modelo de Documento

Você também conseguirá fazer a exclusão de um cadastro de Modelo de Documento clicando em Excluir. Ao excluir esse Modelo você não conseguirá recuperá-lo, nem utilizá-lo nas rotinas do sistema.
