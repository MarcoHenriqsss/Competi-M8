Estoque

Nessa rotina, poderá realizar o envio do estoque de seus produtos no Marketplace.

Marketplace > MOVIMENTO > ECOMMERCE > Estoque

Filtros

  • Exibir: Serão exibidas as seguintes opções:
    • Todos: Listará todos os produtos cadastrados no sistema que possuírem movimentação.
    • Somente ativos: Listará todos os produtos ativos no sistema que possuírem movimentação.
    • Somente Inativos: Listará todos os produtos inativos no sistema que possuírem movimentação.
  • Empresa: Campo disponível para selecionar a empresa, dessa forma será considerado os produtos que foram movimentados na empresa selecionada.
  • Estabelecimento: Campo disponível para selecionar o estabelecimento, dessa forma será considerado os produtos que foram movimentados no estabelecimento selecionado.
  • Cód. Produto/Serviço: Campo disponível para selecionar os produtos e/ou serviços através de seu código de cadastro.
  • Descrição Produto: Campo disponível para selecionar os produtos através da sua descrição cadastrada.
  • Inf. Complementares: Campo disponível para selecionar os produtos através da Informação Complementar, disponibilizada em seu cadastro.
  • Cód. Depósito: Campo disponível para selecionar o depósito, dessa forma, listará todos os produtos que possuem estoque no determinado local de estoque.
  • Família: Campo disponível para selecionar a Família, dessa forma, listará todos os produtos que possuem em seu cadastro esta família informada.
  • Marca: Campo disponível para selecionar a Marca, dessa forma, listará todos os produtos que possuem em seu cadastro esta marca informada.
  • Grupo Estoque: Campo disponível para selecionar o Grupo Estoque, dessa forma, listará todos os produtos que possuem em seu cadastro este Grupo Estoque informado.
  • Data Movimentação Estoque: Campo em formato DD/MM/AAAA permitindo a pesquisa dos produtos que foram movimentados na data em selecionada.

Para pesquisar os produtos desejados, basta clicar em. Ao pesquisar os produtos, serão apresentados na lista abaixo.

Para selecionar os itens a serem enviados ao Marketplace, basta clicar em cima do registro desejado, o mesmo será listado na grid denominada "Itens Selecionados"

Para realizar o envio do saldo do estoque do item selecionado, basta clicar em. Dessa forma, será enviado o estoque disponível de todos os itens listados na Grid "Itens Selecionados". Caso deseje enviar o estoque disponível de todos os produtos de uma única vez, sem a necessidade de listar os mesmos em mesmos em "Itens Selecionados", basta acessar a opção.
