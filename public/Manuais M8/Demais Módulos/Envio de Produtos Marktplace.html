Lista de Produto

Nessa rotina, poderá realizar o envio de novos produtos e/ou atualizar os produtos no Marketplace.

Marketplace > MOVIMENTO > ECOMMERCE > Produtos

Cabeçalho

Para pesquisar os produtos, dispomos dos filtros de pesquisas, no canto superior direito.

Após as buscas, serão listados os produtos em forma de lista. Para selecionar o item, basta clicar em cima do mesmo.

Para realizar o envio dos produtos para o Marketplace, clique em, dessa forma o sistema enviará os produtos selecionados na lista para a loja virtual.

Para excluir os produtos do Marketplace, basta clicar em, dessa forma, o sistema excluirá da loja virtual os produtos selecionados. Para pesquisar todos os itens que estão pendente de envio, basta clicar em, dessa forma o sistema listará todos os produtos configurados porém sem envio a loja virtual. Após a seleção dos produtos,

deverá ser realizado o envio dos mesmos.

Para realizar o envio ou exclusão de todos os produtos de uma única vez, basta acessar a opção
