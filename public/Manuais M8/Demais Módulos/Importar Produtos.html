Importação de Produtos

Esta rotina, lhe permite fazer a importação de vários produtos de uma única vez, através de um arquivo excel.

Utilitários > MOVIMENTO > IMPORTAÇÕES > Importação de Produtos

Ações

  • Baixar Layout: Neste campo você poderá baixar uma planilha com layout padrão de importação dos produtos, para fazer a importação deverá seguir exatamente o layout pré definido.

  • Código Identificação: Poderá informar o código deste produto, caso não tenha o sistema criará um código automaticamente.
  • Código Similaridade: Poderá informar o código de similaridade desse produto, caso possua.
  • Referencia Fabricante: Poderá informar o código de de referencia do fabricante desse produto, caso possua.
  • Código Importação: Poderá informar o código de importação desse produto, caso possua.
  • Origem: Informe o código referente a origem do produto.
  • Classificação: Informe o código referente a classificação do produto, se o mesmo é um produto, bem, equipamento ou produto/equipamento.
  • Nome: Informe o nome do item.
  • Apelido: Poderá informar um apelido para o item.
  • Preço Venda: Informe o preço de venda do produto.
  • Preço Mínimo: Informe o preço de venda mínimo do produto.
  • Unidade: Informe a unidade tributável desse item.
  • NCM: Informe o NCM (Nomenclatura Comum MercoSul) desse produto.
  • Família: Neste campo poderá vincular o produto a uma familia pré cadastrada no sistema.
  • Grupo Estoque: Neste campo poderá vincular o produto a um grupo de estoque pré cadastrado no sistema.
  • Categoria: Poderá informar a categoria do produto.
  • Marca: Poderá informar a marca do produto.
  • Fornecedor: Informe o CNPJ/CPF do fornecedor deste produto, neste campo deverão ser informados apenas dígitos numéricos.
  • Fabricante: Informe o CNPJ/CPF do fabricante deste produto, neste campo deverão ser informados apenas dígitos numéricos.

Após preenchidos os campo na planilha, selecione o arquivo e clique em, desta forma conseguirá visualizar os produtos a serem importados na lista de Produtos logo abaixo.

Caso sua planilha tenha alguma informação divergente, a linha com tal informação será exibida em vermelho para melhor identificação, conforme exemplo abaixo, onde não foi informado o Nome do Produto, esta é uma informação obrigatória.

Após pesquisar os produtos, verificando que todas as informações estão corretas, clique em para iniciar o processo de importação. Vale ressaltar que esse processo por demorar alguns minutos, dependendo da quantidade de produtos informados. Após a importação será exibida uma mensagem de sucesso na sua tela e você poderá localizar os produtos na Lista de Produtos no módulo Estoque.
