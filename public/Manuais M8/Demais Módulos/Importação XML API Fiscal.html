Importação XML API Fiscal

Uma API (Application Programming Interface) é um conjunto de regras e protocolos que permite que diferentes softwares se comuniquem entre si, permitindo que eles troquem informações e compartilhem funcionalidades. No M8, com a configuração da API feita, você poderá fazer a importação de Lançamentos Fiscais, Notas de Entrada e Saída, exceto Faturas de Energia, Telefone e Outras Faturas, para assim utiliza-los em outro sistema.

Utilitários > MOVIMENTO > INTEGRAÇÃO OUTROS SISTEMAS > Integração API Fiscal

Filtros

  • Emissão Inicial: Informe a data inicial e final do período que deseja pesquisar os lançamento para efetuar a exportação.
  • Lançamento Inicial: Informe a data inicial e final de lançamento do período que deseja pesquisar os lançamento e efetuar a exportação.
  • Documento Inicial: Informe um número de documento inicial e final pra filtrar por um intervalo de documentos.
  • Empresa: Poderá escolher uma Empresa para fazer a busca dos documentos, o Sistema vai sempre sugerir a Empresa que está logada.
  • Estabelecimento: Poderá escolher um Estabelecimento para fazer a busca dos documentos, o Sistema vai sempre sugerir o Estabelecimento que está logado.
  • Chave NF-e: Poderá escolher uma única chave de acesso para fazer a pesquisa e exportação.
  • Condição Pagamento: Poderá escolher uma Condição de Pagamento, que foi informada nos documentos, para fazer a busca dos documentos.
  • Tipo Compra: Poderá escolher um Tipo Compra, que foi informada nos documentos, para fazer a busca dos lançamentos, quando informado a opção Entrada no campo Exportar.
  • Exportar: Poderá escolher quais documentos deseja exportar, entradas, saídas ou ambos. Ao marcar as opção Saída de Ambos não será possível fazer a busca por Tipo Compra.
  • Download: Quando marcado, o Sistema realiza apenas o Download dos arquivos (não irá transmitir os dados para a API). Para utilização dessa opção é necessário fazer as configurações de API no caminho Configurações > CADASTROS > CADASTROS > Lista Cadastro de Estabelecimentos, aba Configuração API Contábil.

Após preencher os Filtros desejados, clique em, será exibida logo abaixo uma lista onde você poderá marcar todos ou apenas os documentos que deseja exportar para a API.

Por fim clique em, dessa forma serão enviados os documentos selecionados para a API, e você conseguirá fazer a importação dos documentos e lançamentos em outro software de sua escolha que também tenha comunicação com a API.
