Importação de Cheques

A tela de Importação de Cheques permite que seja feito o lançamento de vários Cheques no sistema de uma vez. Nesse artigo, lhe mostraremos o passo a passo parar executar essa importação.

Utilitários > > IMPORTAÇÕES > Importação de Cheques

Layout Modelo

O layout padrão, o qual pode ser preenchido com os dados desejados para posterior importação, pode ser baixado clicando na opção Ações, em seguida em Baixar Layout. Será gerado um arquivo.xlsx com o modelo para preenchimento.

Campos do Layout de Importação de Cheques

A planilha para importação de Cheques é composta por colunas específicas, cada uma com seu papel na criação/importação dos Cheques. Abaixo, listamos campos e suas descrições:

  • CNPJ Filial: Informe o CNPJ do estabelecimento em que este titulo será lançado, sem pontuação, apenas os números.
  • CNPJ/CPF Cliente ou Fornecedor: Preencha com o CNPJ ou CPF da pessoa ao qual o cheque é destinado, sem pontuação, apenas os números.
  • Conta Origem: Informe o código conta Origem em que este Cheque deve ser vinculado.
  • Conta Destino: Informe o código conta Destino em que este Cheque deve ser vinculado.
  • Bacen: Insira o código bacen deve ser vinculado ao Cheque.
  • Meio de Pagamento: Insira o nome do meio de pagamento deste Cheque, já previamente cadastrado no sistema.
  • Numero do Cheque: Preencha com o número do cheque que será importado.
  • Numero do Documento: Preencha com o número de documento do cheque que será importado.
  • Data Emissão: Preencha com a data de Emissão do Cheque.
  • Data Bom Para: Preencha com a data de "Bom Para" do Cheque.
  • CNPJ CPF Vendedor: Insira o CNPJ ou CPF do vendedor, para que possa ser feito vinculo com o mesmo.
  • Percentual Comissão: Insira o Percentual de comissão que dado ao vendedor.
  • Valor Cheque: Neste campo preencha qual o valor do cheque.
  • Complemento: Este campo é destinado a informações complementares referente a este cheque.

Etapas da Importação

Passo 1: Acesse a tela de Importação de Cheques no sistema. Passo 2: Clique em Selecionar Arquivo e escolha a planilha preenchida com os dados. Passo 3: Clique em Pesquisar. O sistema validará os dados e apresentará o conteúdo da planilha. Caso tenham informações incorretas na planilha, essas informações serão exibidas em vemelho em tela, dessa forma você poderá identificar a ajustar informações na sua planilha.

Após validar, clique em Processar para realizar a importação das Cheques.
