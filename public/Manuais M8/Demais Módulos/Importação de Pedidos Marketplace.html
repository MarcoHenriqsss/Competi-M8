Pedidos

Nessa rotina, você poderá realizar a importação dos pedidos realizados no Marketplace para o M8, dessa forma podendo gerar Notas Fiscais a partir deles.

Marketplace > MOVIMENTO > ECOMMERCE > Pedidos

Filtros

  • Data: Campo de data com formato DD/MM/AAAA permitindo a pesquisa dos pedidos realizados na data selecionada.
  • Status: Campo disponível para seleção dos status dos Pedidos no Marketplace, sendo as opções "A enviar", "Enviado" e "Aguardando Pagamento".

Para pesquisar os pedidos desejados, basta clicar em. Ao selecionar essa opção, os pedidos serão apresentados em tela, para selecioná-los, clique no checkbox na linha do Pedido, em seguida, para importá-

los, basta clicar em. Os Pedidos importados, serão inclusos na lista de Pedidos de Venda Rápido, no módulo Faturamento. Para verificar os pedidos importados, basta clicar em.
