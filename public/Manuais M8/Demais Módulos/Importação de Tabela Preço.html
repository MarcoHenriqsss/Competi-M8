Importação de Tabela Preço

A tela de Importação de Tabela Preço permite que seja feito o lançamento de vários tabelas de preço, bem como diversos itens vinculados as tabelas no sistema de uma vez. Nesse artigo, lhe mostraremos o passo a passo parar executar essa importação.

Utilitários > MOVIMENTO > IMPORTAÇÕES > Importação de Tabela Preço

Layout Modelo

O layout padrão, o qual pode ser preenchido com os dados desejados para posterior importação, pode ser baixado clicando na opção Ações, em seguida em Baixar Layout. Será gerado um arquivo.xlsx com o modelo para preenchimento.

Campos do Layout de Importação de Tabela Preço

A planilha para importação de Tabela Preço é composta por duas abas e cada uma com colunas específicas, cada uma com seu papel na criação/importação dos Tabela Preço. Abaixo, listamos campos e suas descrições:

Tabela

A primeira aba da planilha representa o cabeçalho da Tabela de preço

  • Código Tabela: Campo onde ira inserir o código da tabela de Preço que será importada no sistema (Campo único de cada tabela);
  • Nome: Aqui irá inserir o nome de sua tabela de preço que será importada ao sistema;
  • Percentual de Comissão: Neste campo ira preencher qual percentual de comissão será vinculado a esta tabela de preço (o percentual de 1% será inserido como 1 na planilha );
  • Percentual de Acréscimo: Neste campo ira preencher qual percentual de Acréscimo será vinculado a esta tabela de preço (o percentual de 1% será inserido como 1 na planilha );
  • Percentual de Desconto: Neste campo ira preencher qual percentual de Desconto será vinculado a esta tabela de preço (o percentual de 1% será inserido como 1 na planilha );
  • Calcula Peso Liquido: Neste campo definirá se está tabela irá calcular Peso Liquido ou não (S para Sim, e N para Não) (O valor do preço será calculado: (preço tabela x peso líquido));
  • Observação: Campo onde poderá inserir uma Observação para esta tabela de preço.

Item

A segunda aba da planilha representa os produtos vinculados a uma tabela de preço

  • Código Tabela: Campo onde irá inserir o código de qual tabela de preço este produto será vinculada.
  • Código do Produto: Insira qual o código no sistema do produto que deve se enquadrar na tabela.
  • Código Interno: Poderá inserir neste campo um código interno do produto.
  • Nome do Produto: Insira o nome do produto que será vinculado a tabela.
  • Valor Mínimo Venda: Preencha aqui qual o Valor mínimo de venda deste produto quando vinculado a tabela.
  • Valor Venda: Preencha aqui qual o Valor unitário de venda deste produto quando vinculado a tabela (Este será o valor sugerido nos lançamentos de notas, pedidos...).
  • Código Categoria: Insira o código da categoria no sistema que será vinculada ao produto na tabela de preço (Categoria esta presente no caminho: Estoque > CADASTROS > cadastros Realize os cadastros > Lista Cadastro de Categorias).
  • Código Condição de Pagamento: Insira o código da condição de pagamento que deverá ser vinculada ao produto na tabela de preço.
  • Percentual Comissão Mínimo: Neste campo ira preencher qual percentual de comissão Mínimo que será permitido utilizar no produto vinculado a esta tabela de preço ( o percentual de 1% será inserido como 1 na planilha ).
  • Percentual Comissão Máximo: Neste campo ira preencher qual percentual de comissão Máximo que será permitido utilizar no produto vinculado a esta tabela de preço ( o percentual de 1% será inserido como 1 na planilha ).
  • Percentual Desconto Máximo: Neste campo ira preencher qual percentual de Desconto Máximo que será permitido utilizar no produto vinculado a esta tabela de preço ( o percentual de 1% será inserido como 1 na planilha ).

Etapas da Importação

Passo 1: Acesse a tela de Importação de Tabela de Preço no sistema. Passo 2: Clique em Selecionar Arquivo e escolha a planilha preenchida com os dados. Passo 3: Clique em Pesquisar. O sistema validará os dados e apresentará o conteúdo da planilha.

Após validar, clique em Processar para realizar a importação das Tabelas de Preço. Caso tenha alguma informação divergente, ela será exibida em vermelho na listagem, dessa forma você conseguirá fazer os ajustes necessários na planilha de importação.
