Cadastro de Família

O Cadastro de Família possibilitará a configuração de diversos parâmetros, para uma determinada família de produtos. Dessa forma servindo como um agrupador de itens assim como facilitador para parametrização do seu sistema.

Estoque > CADASTROS > CADASTROS > Lista Cadastro de Famílias

Inclusão de Cadastro de Família

Para incluir um novo Cadastro de Família clique na opção no canto superior esquerdo.

Cabeçalho

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Nome: Nesse campo você deverá informar um nome de identificação desta Família.
  • Código Inteligente: Neste campo você irá informar um código de identificação da família que irá compor o Código de Identificação Interno dos produtos com esta família, seguidos de um sequencial para cada produto.
  • Exibe OS: Esse campo define se os produtos ou serviços vinculados a esta família poderão ou não ser lançados em Ordens de Serviço.
  • Exibe Pedido: Esse campo define se os produtos ou serviços vinculados a esta família poderam ou não ser lançados em Pedidos.
  • Exibe Orçamento: Esse campo define se os produtos ou serviços vinculados a esta família poderam ou não ser lançados em Orçamentos.
  • Gerar Código Interno: Quando marcado, habilitará os campos:
    • Prefixo: Informe a numeração que será fixa no Código Interno dos produtos.
    • Nr: Sequencial: Informe o valor inicial do sequencial que será gerado para cada produto após o prefixo para geração do Código Interno de cada produto vinculado a essa família.
    • Tamanho Código: Informe o número de caracteres que será acrescido ao ao prefixo como código sequencial.
  • Observação: Campo de descrição livre para informações referentes a esta Família.

Após preencher os campos, clique em para que o cadastro seja finalizado.

Edição de Cadastro de Família
Ao acessar a tela, você conseguirá listar todos as Cadastro de Família ou filtrá-las de acordo com os filtros disponíveis na tela, para editá-las clique no botão Editar.

Exclusão de Cadastro de Família
Você também conseguirá fazer a exclusão de uma Cadastro de Família clicando em Excluir. Ao excluir essa Cadastro de Família, apenas um usuário Administrados conseguirá recuperar o registro, se necessário, clicando em Restaurar Registro.
