Cadastro de Grupos de Estoque

O Grupo de Estoque possibilitará a configuração de diversos parâmetros, tais como: lucro estimado, se os itens vão participar do inventário, percentual de comissão e a opção de calcular ou não o Custo de Mercadoria Vendida (CMV) para um determinado grupo de produtos. Dessa forma servindo como um agrupador de itens assim como facilitador para parametrização do seu sistema.

Caminho de Acesso: Modulo Estoque > CADASTROS > CADASTROS > Lista Cadastro de Grupos de Estoque

Inclusão de Grupo Estoque

Para incluir um novo Grupo de Estoque clique na opção no canto superior esquerdo. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

Cabeçalho

  • Código: Código de identificação interna, gerado automaticamente pelo sistema.
  • Nome: Definirá qual o nome do seu novo Grupo Estoque.
  • Família: Deverá definir a qual família esse novo Grupo Estoque pertence.
  • Participa inventario: Essa opção possibilitará que os produtos que forem locados dentro desse novo Grupo Estoque participem do inventário. Dessa forma serão exibidos nos relatórios e arquivos de estoque inventário.
  • Atualiza CMV Venda: Definirá se será atualizado o CMV (Custo da Mercadoria Vendida) para produtos que estiverem alocados nesse Grupo Estoque.
  • Lucro estimado: Campo para que seja informada percentagem de lucro estimado na venda dos produtos que farão parte desse Grupo de Estoque.
  • Lucro estimado Mínimo: Campo para que seja definido a percentagem de Lucro Mínimo Estimado para os produtos que fizerem parte desse Grupo Estoque.
  • Desconto Máximo: Nesse campo poderá informar a percentagem máxima de desconto para os produtos que estiverem alocados neste Grupo Estoque.
  • Atualizar CMV Venda: Quando utilizado irá atualizar o CMV (Custo da Mercadoria Vendida) no momento que foi efetuada a venda do produto que está alocado neste Grupo Estoque.
  • Integração Mobile: Quando marcado como sim, os itens participantes desse Grupo de Estoque poderão ser utilizados no App Força Vendas da M8.
  • Observação: Campo livre para observação referente ao Grupo Estoque cadastrado.

Comissões

Nesta aba poderão ser definidas percentagens de comissão nas venda dos itens participantes deste grupo para os vendedores da sua empresa.

  • Código: Código de identificação interna do lançamento de comissão, gerado automaticamente pelo sistema.
  • Vendedor: Informe o vendedor para o qual deseja estabelecer a percentagem de comissão.
  • % Comissão: Informe a percentagem de comissão que será aplicada sobre os itens nas vendas feitas pelo vendedor informado acima.

Após preenchidos os campo, clique em para que as informações sejam exibidas na listagem abaixo, dessa forma poderá fazer novos lançamentos.

Edição de Grupo Estoque

Ao acessar a tela, você conseguirá listar todos os Grupos Estoque cadastrados ou filtrá-los conforme os filtros disponíveis na tela, para editá-las clique no botão Editar.

Exclusão de Grupo Estoque

Você também conseguirá fazer a exclusão de um Grupo Estoque, clicado em Excluir. Ao excluir esse lançamento, você não conseguirá recuperá-lo e também não poderá utilizá-lo em nenhuma rotina do sistema.
