Cadastro de Unidade de Conversão - Venda

O Cadastro de Fator de Conversão - Venda no M8, é utilizado em vendas onde os produtos precisam ser convertidos de uma unidade de medida para outra. Um exemplo, pode ser parafusos, onde você compra do seu fornecedor em pacotes, porém faz a venda em unidade, logo precisaria fazer a conversão.

Estoque > Cadastro > CADASTROS > Lista Cadastro de Unidade Conversão - Venda

Inclusão de Unidade de Conversão - Venda

Para adicionar uma nova unidade de conversão, basta clicar no botão adicionar e, caso deseja pesquisar uma unidade já cadastrada, informar o código da conversão/produto ou o nome do produto, no campo de pesquisa.

Cabeçalho

  • Código: Gerado automaticamente pelo sistema.
  • Produto: Informar o produto que será realizado a conversão de unidade.
  • Padrão: Ao ativar essa flag, toda vez que esse produto for lançado em uma rotina de venda, como Pedidos e Notas Fiscais, será atribuída essa Unidade de Conversão a ele.
  • Método Conversão: Informar qual será o método utilizado para a conversão, caso seja conversão de largura, possui a opção para informar.
  • Unidade de Destino: Informará a unidade que o produto irá ser convertida.
    • Exemplo: Meu produto entra em caixa e preciso converter para peça, vou informar a unidade de destino peça, conforme esta cadastro da unidade.
  • Código de barra: Caso opte, pode informar o código de barra do produto nesse campo. (esse campo não é obrigatório).
  • Preço Venda: Caso opte, esse campo é para informar o preço de venda do produto. (esse campo não é obrigatório).
  • Fator conversão Largura: Caso no campo "Método de conversão", foi preenchida a opção de conversão Largura, deve preencher esse campo com o fator de conversão. O sistema realizará o cálculo da seguinte maneira: (Fator de Conversão Largura* Fator de Conversão).
    • Exemplo: (4,00 x 0,20) Fator de Conversão= 0,8.
  • Fator Conversão: Informará nesse campo o fator da conversão, onde o sistema realizará o cálculo da seguinte maneira: quantidade do produto vezes o fator da conversão.
    • Exemplo: Meu produto está em caixa, mas vou realizar a venda em peças, cada caixa possui 12 peças. Logo meu fator de conversão será 12.
Atenção: a informação inserida no campo Fator de Conversão será utilizada como base pelo sistema para realizar os cálculos automaticamente. Por isso, é essencial validar esse dado antes de utilizá-lo, garantindo que esteja correto.
