Etiquetas

Esta tela possibilita a geração de Etiquetas dos Produtos, podendo fazer impressões múltiplas e em grandes quantidades de produtos diferentes.

Estoque > MOVIMENTO > MOVIMENTOS > Etiquetas

Filtros

  • Código Inicial: Informe os códigos de produtos que deseja buscar, contendo início e fim, Ex: Produtos do Cód 1200 à 12100;
  • Data de Atualização: Poderá filtrar pela Data de Atualização dos Produto, colocando o intervalo desejado nos campos.
  • Nome: Utilize este campo para filtrar um Produto em específico pelo seu nome, ou uma palavra que contenha dentro de múltiplos produtos, Ex: Ferro;
  • Código Barra: Podendo definir para buscar um Código de Barras em específico;
  • Tabela de Preço: Definição de uma tabela de preço, caso queira pesquisar somente produtos de determinada Tabela;
  • Validar Tabela Preço: Flag que permite validar ou não a tabela de preço definida;
  • Produto: Poderá preencher um ou mais cadastros de produtos específicos para filtrar a busca;
  • Grupo Estoque: Caso queira filtrar um Grupo Estoque especifico, poderá selecionar-ló neste campo;
  • Família: Segue a mesma definição do Grupo Estoque, caso queira filtrar uma família específica;
  • Marca: Segue a mesma definição do Grupo Estoque, caso queira filtrar uma marca específica;
  • Localização Estoque: Poderá informar a localização de estoque específica para busca;
  • Etiquetas em Branco: Define a quantidade de Etiquetas em Branco que deseja gerar por produto;
  • Nr Etiquetas: Define qual número de etiquetas por produto selecionado que deseja gerar;
  • Nota de Entrada: Caso queira filtrar produtos de uma Nota de Entrada específica, poderá selecionar neste campo esta Nota;
  • Nota de Saída: Caso queira filtrar produtos de uma Nota de Saída específica, poderá selecionar neste campo esta Nota;
  • Modelo Etiqueta: Define a forma que serão geradas as etiquetas, tendo a opção de 1 até 10 colunas, e Gôndola.

Gerar Etiqueta

Para gerar etiqueta, basta selecionar produto desejado, e clicar em Imprimir.

Com isso será aberta em tela a impressão das etiquetas, o layout exibido na imagem acima é apenas uma exemplo, essa etiqueta pode ser personalizada conforme necessidade da sua empresa.
