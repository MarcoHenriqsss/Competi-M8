Manutenção PIS/COFINS

Esta rotina permite realizar a manutenção de informações relacionadas ao PIS e à COFINS, possibilitando a atualização em massa de dados como Operação Fiscal, Custos, Percentuais e outras configurações, de forma prática e centralizada.

Fiscal > MOVIMENTO > MANUTENÇÃO > Manutenção Pis/Cofins

Filtros

  • Movimento: Nesta opção, você define o tipo de movimentação que será atualizado, selecionando a origem dos documentos:
    • Entrada.
    • Saídas.
  • Empresa: Permite selecionar a empresa à qual pertencem os documentos a serem atualizados.
  • Estabelecimento: Define os estabelecimentos vinculados aos documentos selecionados para atualização.
  • Data de: Campo utilizado para delimitar o período de busca dos documentos.
  • Documento de: Campo destinado à definição dos números dos documentos que deverão ser filtrados.
  • CFOP: Campo destinado à definição do CFOP que será utilizado como critério na busca pelos documentos
  • Operação Fiscal: Permite especificar a Operação Fiscal a ser utilizada na filtragem dos documentos.
  • CST PIS/COFINS: Campo utilizado para definir o código CST de PIS/COFINS que servirá como filtro na busca dos documentos.

Dados de Manutenção

  • Reprocessar Regras: Ao marcar esta opção, será obrigatório informar uma Operação Fiscal. O sistema reprocessará os documentos com base nas regras de impostos vinculadas à operação informada.
  • Recalcular Custos: Quando habilitado, o custo dos itens nos documentos fiscais será reprocessado conforme as regras definidas na Operação Fiscal informada.
  • CST PIS/COFINS: Campo utilizado para definir o novo código CST de PIS/COFINS que será aplicado nos documentos selecionados.
  • Tipo Crédito: Permite informar o novo código de Tipo de Crédito que será atualizado nos documentos.
  • Operação Fiscal: Campo destinado à definição da nova Operação Fiscal que será aplicada nos documentos selecionados.
  • Receita Bruta Presumida%: Percentual utilizado no processo de apuração da ECF – Bloco P, referente ao regime de Lucro Presumido para fins de IRPJ.
  • Percentual de CSLL Presumido%: Percentual utilizado no processo de apuração da ECF – Bloco P, referente ao regime de Lucro Presumido para fins de CSLL.
  • Campos Atualizar: Permite selecionar campos adicionais que serão atualizados nos itens do documento fiscal, conforme necessário:
    • Base Cálculo Pis
    • Base Cálculo Cofins
    • Valor Pis
    • Valor Cofins
    • Alíquota Pis
    • Alíquota Cofins
  • Valor Atualizar: Campo utilizado para informar o novo valor que será aplicado, conforme os campos selecionados na opção Campos a Atualizar.

Para realizar a busca dos Documentos, utilizando os filtros a cima, basta clicar no botão

Após filtrados os itens, selecione os desejados clicando no checkbox.

Para realizar a manutenção do(s) produto(s) e documento(s) selecionado(s), basta clicar no botão.
