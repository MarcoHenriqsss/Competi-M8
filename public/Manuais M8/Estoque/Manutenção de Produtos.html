Manutenção de Produtos

Nessa rotina você conseguirá realizar a manutenção de produtos de forma geral, permitindo atualizar vários produtos de uma única vez.

Caminho de acesso: Estoque > MOVIMENTO > MOVIMENTO > Manutenção de Produtos

Filtros

  • Campo Atualizar: Nessa opção, você determinará o que será atualizado do produto(s) selecionado(s).
    • Valor Venda.
    • Valor Custo Última Compra.
    • Valor Última Compra.
    • Valor Venda Estab. [Regra].
    • Grupo Estoque.
    • Família.
    • Marca.
  • NCM.
  • Categoria.
  • Fornecedor.
  • Localização.
  • Alíq. IPI.
  • CEST.
  • Mínimo Estab.
  • Máximo Estab.
  • Dias Reposição Estab.
  • Fora de Linha.
  • Aplicação.
  • Método Atualizar: Nessa opção, você determinará a forma de atualização.
    • Valor [=]: Irá igualar o valor informado ao valor do produto.
    • Valor[+]: Irá adicionar o valor informado no valor do produto.
    • Valor[-]: Irá subtrair o valor informado no valor do produto.
    • Valor - % [+]: Irá adicionar o percentual informado no valor do produto.
    • Valor - % [-]: Irá subtrair o percentual informado no valor do produto.

Dados de Atualização

  • Valor Atualizar: Campo disponível para informar no novo valor que será atualizado.

Filtros

  • Estabelecimento: Campo obrigatório para selecionar o estabelecimento em que serão realizadas as atualizações.
  • Nome Produto: Campo disponível para busca do produto através do nome.
  • Produto: Campo disponível para busca do produto específico.
  • Grupo Estoque: Campo disponível para busca de produtos através do Grupo Estoque.
  • Família: Campo disponível para busca de produtos através da Família.
  • Marca: Campo disponível para busca de produtos através da Marca.
  • NCM: Campo disponível para busca de produtos através da NCM.
  • Fornecedor: Campo disponível para busca de produtos através do Fornecedor.
  • Localização: Campo disponível para busca de produtos através da Localização.

Para realizar a busca dos produtos, utilizando os filtros a cima, basta clicar no botão.

Após filtrados os itens, selecione os desejados clicando no checkbox.

Para realizar a manutenção do(s) produto(s) selecionado(s), basta clicar no botão.
