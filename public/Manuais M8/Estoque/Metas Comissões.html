Metas Comissões

Este processo tem como objetivo configurar as metas por vendedores ou de forma generalizada para todos os vendedores do Estabelecimento.

Financeiro > MOVIMENTO > COMISSÕES > Metas

Inclusão de Metas de Comissões

Para adicionar uma nova meta, basta clicar em.

Cabeçalho

  • Código: Código de identificação interna, gerado automaticamente pelo sistema.
  • Meta Estabelecimento: Quando marcado, a meta será aplicada globalmente a todos os vendedores quando a meta do estabelecimento for alcançada. Quando uma meta global é definida, não é necessário especificar o vendedor.
  • Estabelecimento: Campo disponível para especificar o estabelecimento relacionado à meta correspondente.
  • Vendedor: Campo disponível para especificar o vendedor quando a meta global não é utilizada.
  • Data Inicial: Campo disponível para indicar a data inicial que será considerada na definição da meta.
  • Data Final: Campo disponível para indicar a data final que será considerada na definição da meta..
  • Valor Inicial: Campo disponível para especificar a faixa de valor inicial que será considerada na meta.
  • Valor Final: Campo disponível para especificar a faixa de valor final que será considerada na meta..
  • % Comissão: Campo disponível para especificar a porcentagem de comissão que será aplicada quando a respectiva meta for atingida.

Após realizar o preenchimento dos campos mencionados acima, basta clicar nas opções Salvar
