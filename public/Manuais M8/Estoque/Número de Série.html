Número de Série

Tela utilizada para visualizar como foi utilizado os números de série, dia em que foi dado entrada, juntamente dos vínculos de Entrada e Saída do número da série.

Estoque > MOVIMENTO > CONSULTA > Consulta Número de Séries

Séries Cadastradas

  • Ações: Permite editar dados do Número de Série utilizado (Lápis);
  • Produto: Lista código e nome do produto;
  • Apelido: Lista o Apelido do Produto definido no Cadastro do Produto;
  • Cód Interno: Lista o código interno do produto, se definido no Cadastro do Produto;
  • Nro. Série: Traz o Número de Série que foi criado para o Produto;
  • Data Entrada: Data em que foi dado entrada neste Número de Série;
  • Documento Entrada: Conforme print acima, ele traz em qual Documento/Registro foi criado este número de Série, nesta coluna os registros exibidos são link, ao clicar você será redirecionado para o lançamento do
  • documento.
  • Documento Saída: Conforme print acima, ele traz em qual Documento/Registro foi dado saída no Número de Série, nesta coluna os registros exibidos são link, ao clicar você será redirecionado para o lançamento do documento.
