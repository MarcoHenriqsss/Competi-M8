Transferência de Estoque Múltipla

A Transferência de Estoque Múltipla é um processo que permite a movimentação de quantidades específicas de produtos entre locais de estoque cadastrados em seu sistema. Essa rotina lhe permite transferir o estoque de diversos produtos de uma única vez.

Estoque > MOVIMENTO > MOVIMENTO > Transferência de Estoque Múltipla

Inclusão de Transferência de Estoque

Para incluir uma nova transferência de estoque múltipla, clique na opção no canto superior esquerdo. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

Cabeçalho

  • Código: Código de identificação interno gerado automaticamente pelo sistema.
  • Status: Status do lançamento, sendo pendente, processado, encerrado ou cancelado.
  • Data Lançamento: Data que será gerada a movimentação de estoque.
  • Estabelecimento Origem: Estabelecimento origem do local de estoque origem. Será trazido pelo sistema o estabelecimento logado e será o mesmo que o estabelecimento de destino.
  • Estabelecimento Destino: Será trazido o estabelecimento logado, este será o estabelecimento destino da transferência.
  • Observações: Campo para incluir bservações sobre o lançamento.

Após preenchidos os campo, clique em. Após salvar o cabeçalho, deverá lançar os itens na transferência.

Itens

  • Código: Código de identificação interno gerado automaticamente pelo sistema.
  • Produto: Informe o produto que irá transferir entre os locais de estoque.
  • Unidade: Unidade de medida que será informada de acordo com o cadastro de seu produto.
  • Quantidade: Quantidade do produto que será transferida.
  • Custo Atual: Será exibido o custo atual do produto conforme movimentações de estoque do mesmo.
  • Custo Total: Será exibido o resultado da multiplicação da quantidade informada e custo atual.
  • Centro Custo Origem: Caso deseje transferir o custo de produtos entre centros de custo, deverá utilizar esse campo para informar de onde sairá esse custo.
  • Local Estoque Origem: Local de estoque origem da movimentação, nesse será feita a saída do estoque.
  • Centro Custo Destino: Informe o Centro de Custo onde entrará este custo.
  • Local Estoque Destino: Local de estoque destino da movimentação, nesse será feita entrada do estoque.
  • Ordem Produção: Caso sua transferência seja feita para utilização em uma Ordem de Produção específica, você poderá informá-la nesse campo.
  • Ordem Serviço: Caso sua transferência seja feita para utilização em uma Ordem de Serviço específica, você poderá informá-la nesse campo.
  • Requisição: Caso sua transferência seja feita para utilização em uma Requisição específica, você poderá informá-la nesse campo.

Ações

Para Imprimir a transferência, basta acessar a opção Imprimir Espelho, contida no menu Ações Para processar a transferência, basta acessar a opção Processar, contida no menu Ações. Para Cancelar a transferência, basta acessar a opção Cancelar, contida no menu Ações. Para Baixar o Layout de Importação da transferência, basta acessar a opção Baixar Modelo Excel, contida no menu Ações.
Para Importar o modelo Excel da transferência, basta acessar a opção Importar Arquivo Excel, contida no menu Ações.
