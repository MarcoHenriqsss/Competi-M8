Configuração de Status de Controle de Entrega

Esse cadastro deverá ser feito para utilizar a tela de Análise de Controle de Entrega.

Faturamento > CADASTROS > CADASTROS > Lista Cadastro de Status

Cabeçalho

  • Código: Código de identificação do registro, será gerado automaticamente pelo sistema.
  • Nome: Poderá informar o nome do status conforme necessidade da Empresa.
  • Nome Abreviado: Poderá informar uma abreviatura do nome do status.
  • Destino: Nesse caso, para Analise do Controle de Entrega, deverá ser preenchida a opção 8- Entrega.
  • Status: Nesse campo existem três opções, sendo elas:
    • Avançar: Deverá selecionar para os status onde usuário irá somente avançar o fluxo do Pedido.
    • Pronto Faturar: Marque essa opção para criar um status onde o usuário conseguirá faturar Notas de Venda de Entrega Futura na tela de Análise de Controle de Entrega.
    • Finalizado: Selecione essa opção para criar um status como Finalizado, onde vão ficar os Pedidos depois de feito todo o processo de Controle de Entrega.
  • Permite Impressão: Quando marcado como sim, será possível fazer a impressão do Romaneio quando o Pedido estiver nesse status em questão.
  • Observação: Poderá informar uma observação sobre esse status, essas informações ficaram vinculadas apenas ao Cadastro deste status, não será levada para outros cadastros relacionados.

Usuários

Nesta aba será possível visualizar todos os usuário que tem acesso a este status. Essa aba será apenas para visualização, a seguir informo o passo a passo de como vincular esse status ao usuário.

Como vincular o status ao Usuário

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Usuários

Dentro do cadastro do usuário desejado, deverá abrir a aba Status Controle Entrega.

Clicando em Novo, conseguirá inserir os status desejados.

  • Código: Código de identificação gerado automaticamente pelo sistema.
  • Status Entrega: Deverá selecionar o status configurado.
  • Bloquear Avançar: Quando marcado, ao chegar nesse status, o usuário não conseguirá avançar para o próximo.
  • Bloquear Retroceder: Quando marcado, ao chegar nesse status o usuário não conseguirá retroceder para o status anterior.

Depois de preenchido os campos, clique em Salvar para que o mesmo fique na Listagem abaixo, dessa forma conseguirá inserir um novo status. A ordem dos status nessa tela determinaram a ordem que o usuário visualizará os status na tela de Analise de Controle de Entrega, depois de inserido todos os status, você poderá arrastá-los, clicando e movendo para ordem que precisa.
Lembrando que essa configuração deve ser feita para cada usuário que terá acesso a tela de Análise, na ordem desejada para cada um e também os status liberados para cada um.

Edição Status de Entrega

Ao acessar a tela, você conseguirá listar todos os Status ou filtrá-los de acordo com os filtros disponíveis na tela, para editá-las clique no botão Editar.

Exclusão Status de Entrega

Você também conseguirá fazer a exclusão de um Status clicado em Excluir. Ao excluir esse Status você não conseguirá recuperá-lo e também não poderá utilizá-lo em nenhuma rotina do sistema.
