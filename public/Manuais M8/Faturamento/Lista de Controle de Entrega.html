Lista de Controle de Entrega

No Cadastro de Controle de Entrega, é possível registrar o pedido, o cliente, o transportador e o motorista. Nesse cadastro, você poderá incluir todos os detalhes referentes ao envio do pedido, como os produtos envolvidos, o status do fluxo de entrega, a quantidade prevista para entrega, a quantidade efetivamente entregue e o saldo restante.

Faturamento > MOVIMENTO > CARGAS > Lista de Controle de Entregas

Inclusão de Cadastro de Controle de Entrega Para incluir um novo Cadastro de Controle de entrega clique na opção no canto superior esquerdo.

Para incluir um novo Cadastro de Controle de entrega clique na opção no canto superior

Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

  • Código: Código sequencial de identificação gerado automaticamente pelo sistema.
  • Status: Status gerado automaticamente pelo sistema.
  • Pedido: Preencha com o código do pedido rápido, previamente cadastrado.
  • Cliente: Informe o cliente, ou seja, o destinatário desse Controle de Entrega.
  • Transportador: Informe a transportadora responsável pelo transporte da carga.
  • Veículo: Informe o veículo que será utilizado pela transportadora para o transporte da carga.
  • Motorista: Informe o cadastro do motorista responsável pelo transporte.
  • Placa: Placa do veículo utilizada no transporte.
  • UF Placa: Informe a Unidade Federativa (UF) da placa do veículo, indicando o estado de origem.
  • Data de Emissão: Data em que o cadastro do controle de entrega foi emitido.
  • Data de Entrega: Informe a data prevista para a entrega da mercadoria.
  • Status do Fluxo de Entrega: Indique o status atual da entrega, como "Em separação", "Pronto para entrega" ou "Entregue".
  • Produto: Informe o produto que será transportado.
  • Unidade: Indique a unidade de medida do produto (ex: sacas, toneladas, quilogramas, caixas).
  • Quantidade: Quantidade do produto informada no pedido.
  • Quantidade Entregue: Informe a quantidade que será ou já foi entregue. Exemplo: se o pedido tem 10 unidades e foram entregues apenas 6, informe 6 unidades
  • Saldo: Campo calculado automaticamente pelo sistema, subtraindo a quantidade entregue da quantidade do pedido. No exemplo acima, o saldo será 4 unidades.
  • Observações: Campo livre para inserir informações complementares, se necessário.

Após preencher os campos, clique em, para que sejam liberadas as demais abas no cadastro do lado esquerdo da tela.

Ocorrências

Se houver alguma ocorrência poderá estar preenchendo nessa aba.

  • Código: Código sequencial gerado automaticamente pelo sistema
  • Motivo da Ocorrência: Informar o motivo da ocorrência, poderá cadastrar no atalho (+) se não houver ocorrência registrada
  • Usuário: Gerado automático pelo sistema, preenchendo o campo com usuário que está cadastrando a ocorrência.
  • Observações: Poderá preencher com informações complementares.

Logo após inserir a ocorrência se houver, clique em para que o registro seja lançado na listagem abaixo, dessa forma você poderá lançar um novo item, assim editá-lo.

Histórico

Sistema irá informar nessa aba, históricos do pedido.

Anexos

Poderá importar arquivos ou foto pelo celular, informar informações complementares sobre o produto, ou foto do produto que esta sendo transportado.

  • Código: Código interno gerado automaticamente pelo sistema.
  • Fotos pelo Celular: Através da leitura do QR-Code com um Smartphone, o sistema direciona o usuário para um link com esse controle de entrega, onde todos os arquivos e imagens que o usuário incluir por esse link irão aparecer na grid de anexos do Cadastro.
  • Descrição: Campo onde será informado nome para identificação do anexo.
  • Arquivo: Campo onde será possível selecionar o arquivo desejado.

Após preencher os campos, clique em para que o item seja lançado na listagem abaixo, dessa forma você poderá lançar um novo item, assim como editá-lo.
