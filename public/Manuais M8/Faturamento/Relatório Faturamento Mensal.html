Relatório Faturamento Mensal

Este Relatório permite que você tenha um controle mensal dos valores faturados, assim como devoluções dos mesmo períodos.

Faturamento > RELATÓRIOS > FATURAMENTO MENSAL > Faturamento

Filtros

  • Formato Impressão: Selecionar o modelo desejado para impressão.
  • Filtrar Data: As informações serão filtradas pela sua data de emissão.
  • Data de: Informe o período que deseja filtrar as informações para exibição no relatório
  • Modelo: Seleciona o modelo desejado para este relatório, se completo ou simplificado.
  • Exibir Filtros Utilizados: Marque essa opção para que sejam exibidos os filtros utilizados na impressão do relatório.
  • Empresa: Selecione a Empresa que deseja utilizar para filtrar as informações do relatório.
  • Estabelecimento: Selecione o Estabelecimento que deseja utilizar para filtrar as informações do relatório.
  • Produto: Selecione os produtos que deseja filtrar.
  • Pessoa: Selecione as Pessoas que deseja filtrar.
  • Região: Selecione as Regiões que deseja filtrar.
  • Vendedor: Selecione os Vendedores que deseja filtrar.
  • Condição Pagamento: Selecione as Condições de Pagamento que deseja filtrar.
  • Família: Selecione as Famílias que deseja filtrar.
  • Marca: Selecionar as Marcas que deseja filtrar.
  • NCM: Preencher os NCM que desejar filtrar.
  • Status: Selecione os Status que deseja filtrar.
  • Grupo Econômico: Selecione os Grupos Econômicos desejados.
  • Atividade: Preencher as Atividade desejadas.
  • Tipo Sped: Selecione os Tipo Sped desejados para filtrar as informações do relatório.
  • Operação Fiscal: Selecione as Operações Fiscais que deseja filtrar.
  • Exibir Assinatura Sócios: Marque se deseja que seja exibida ou não a Assinatura do Sócio na impressão do relatório.
  • Exibir Assinatura Contador: Marque se deseja que seja exibida ou não a Assinatura do Contador na impressão do relatório.
  • Classificação: Selecione as Classificações desejadas para filtrar as informações do relatório.

Relatório

Após preenchidos os filtros desejados, clique em, dessa forma o mesmo será exibido em tela. Este contém as informações de Receita de Venda, Receita de Serviços, Devoluções e um totalizador das colunas citadas, separadamente pelos meses filtrados. Você poderá fazer o download desse arquivo assim como fazer a impressão do mesmo.
