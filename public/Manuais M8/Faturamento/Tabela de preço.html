Tabelas de Preço

A Tabela de Preço é uma funcionalidade que permite que diferentes produtos tenham preços de venda para diferentes cenários.

Faturamento > CADASTROS > CADASTROS > Lista Cadastro de Tabelas de Preço

Inclusão Tabela de Preço

Para incluir uma nova Tabela de Preço clique na opção no canto superior esquerdo. Para te auxiliar no cadastro de uma nova Tabela de Preço, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

Cabeçalho

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Nome: Nome de identificação da Tabela de Preço.
  • % Comissão: Quando informada a alíquota será calculada a comissão para o vendedor que estiver utilizando essa Tabela de Preço.
  • % Acréscimo: Quando informada a alíquota será calculado acréscimo na venda que estiver utilizando essa Tabela de Preço.
  • % Desconto: Quando informada a alíquota será calculado desconto na venda que estiver utilizando essa Tabela de Preço.
  • Calc. Peso Líquido: Quando marcado será calculado o preço de venda do produto multiplicando pelo peso líquido informado na venda.
  • Integração Mobile: Quando marcado essa tabela também será utilizada. no aplicativo Mobile.
  • Código Importação: Se a Tabela de Preço foi importada de outro sistema, deverá ser informado nesse campo o código anterior dela, também poderá ser utilizado para informar o código dessa Tabela de Preço do seu Marketplace.
  • Observação: Observações referente a Tabela de Preço.

Após concluir a revisão de todos os campos, clique em para criar o registro da Tabela de Preço. Em seguida será exibida outra aba para preenchimento no canto esquerdo, sendo ela:

Itens

  • Código: Código sequencial para cada item lançado, gerado automaticamente pelo M8.
  • Produto/Serviço: Nesse campo você informará o produto ou serviço que será utilizado na Tabela de Preço.
  • Categoria: Nesse campo você preencherá a categoria do produto, para controle mais detalhado da Tabela de Preço.
  • Condição de pagamento: Quando informada, você só conseguirá informar esse item quando utilizar essa Condição de Pagamento.
  • Valor Mínimo: Definirá qual o valor mínimo que esse produto poderá ser vendido quando utilizado essa Tabela de preço.
  • Valor Venda: Definirá o valor de venda que será preenchido no lançamento do produto quando informada essa Tabela de Preço.

Após preencher os campos, clique em para que o item seja lançado na listagem abaixo, dessa forma você poderá lançar um novo item, assim como editá-los.

Edição Tabela de Preço

Ao acessar a tela, você conseguirá listar todas as Tabelas de preço ou filtrá-las de acordo com os filtros disponíveis na tela, para editá-las clique no botão Editar.

Exclusão Tabela de Preço

Você também conseguirá fazer a exclusão de uma Tabela de Preço, clicado em Excluir. Ao excluir essa Tabela de Preço você não conseguirá recuperá-la, e não conseguirá utiliza-la nas rotinas de faturamento.
