Tipos de Orçamentos de Faturamento

Nesse cadastro serão feitas as parametrizações necessárias para criar um Orçamento de Faturamento no sistema. Nele serão configuradas e outras informações relevantes.

Faturamento > CADASTROS > CADASTROS > Lista Cadastro Tipos Orçamentos

Inclusão de Tipos de Orçamento de Faturamento

Para incluir um novo Cadastro de Tipo de Orçamento de Faturamento clique na opção no canto superior esquerdo. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

Cabeçalho

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Nome: Deverá ser informada a descrição de identificação desse Tipo de Orçamento.
  • Tipo Documento: Tipo do Documento que será utilizado nas Notas Fiscais emitidas a partir dos Orçamentos utilizando esse Tipo de Orçamento.
  • Status Restrição: Poderá ser vinculado um status de restrição do CRM a este Tipo de Orçamento, ao gerar um Pedido/Ordem de Serviço/Nota Fiscal, caso possua alguma restrição, será exibido uma nova aba de Restrições, onde poderão ser verificadas as restrições e também feito as liberações dessas restrições.
  • Tipo Pedido: Será utilizado este Tipo de Pedido, ao gerar um novo Pedido a partir dos Orçamentos lançados com esse Tipo de Orçamento.
  • Habilita Aba Manutenção: Quando marcado, será habilitada a aba Manutenção no Orçamento.
  • Habilita Aba Itens: Quando marcado, será habilitada a aba de Itens no Orçamento.
  • Habilita Aba Serviços: Quando marcado, será habilitada a aba de Serviços no Orçamento.
  • Habilita Aba Parcelas: Quando marcado, será habilitada a aba de Parcelas no Orçamento.
  • Habilita Aba Equipamentos: Quando marcado, será habilitada a aba de Equipamento no Orçamento.
  • Iniciar Itens Aprovados: Quando marcado, ao inserir itens no Orçamento os mesmos já virão aprovados.
  • Permite Alterar Cliente: Quando marcado, permitirá alterar o cliente, após salvo o cabeçalho do Orçamento.
  • Valor Unitário: Neste campo você poderá selecionar a opção que será utilizada como base para o valor unitários dos itens incluídos no Orçamento, sendo as opções: Preço de Venda, Custo Médio, Custo Operação, Custo Última Compra, Custo Médio Mês Anterior.
  • Informar Tabela Preço: Quando utilizada a opção Sim, será habilitado um campo para informar a Tabela de Preço no Orçamento, este campo se tornará obrigatório.
  • Indicador Presença: Definirá o indicador de presença da venda, quando a Nota Fiscal for gerada diretamente a partir do Orçamento.
  • Destino Ordem Serviço: Definirá se a Ordens de Serviço geradas a partir do Orçamento serão destinadas ao módulo Faturamento ou Assistência Técnica.
  • Método Faturamento: Configuração válida para a geração de Pedidos e Ordem de Serviços através do Orçamento, onde poderá ser selecionada opção de gerar apenas Produto, Serviços ou ambos.
  • Classificação Obrigatória: Quando marcado, será obrigatório informar a classificação do cliente.
  • Utiliza Grade Comissão: Quando marcado, será gerada a comissão para o vendedor do Orçamento de acordo com a Grade de Comissão informada no Cadastro de Vendedor.
  • Contrato Obrigatório: Quando marcado, será obrigatório o preenchimento do campo Contrato no Orçamento.
  • Validar Valor Mínimo: Quando marcado, será validado se valor de venda informado no Orçamento atinge o valor de venda mínimo informado no Cadastro do Produto.
  • Frete Obrigatório: Quando marcado, será obrigatório informar valor de frete.

  • Alterar Classificação: Permite alterar classificação do Orçamento quando o cliente for do Tipo Pessoa Física.
  • Considerar Último Custo: Quando habilitado será considerada a última movimentação com custo maior que zero.
  • Validar Total: Quando marcado, não irá permitir lançar produtos ou serviços com valor menor ou igual a zero.
  • Motivo Desaprovar: Quando marcado, ao desaprovar um dos itens do Orçamento será habilitado em tela um campo para informar o motivo de tal ação.
  • Atualizar Valores/Preços: Quando marcado será atualizado automaticamente os valores da Ordem de Serviço se alterada a Condição de Pagamento.
  • % Margem Líquida: Caso o Orçamento não atinja a % de margem líquida cadastrada, serão bloqueadas as opções do menu Ações e da Aba de Impressão.
  • Observações: Campo de descrição livre para informações complementares referente este Tipo de Orçamento, essas informações serão levadas aos Orçamentos emitidos com esse Tipo.

Edição Tipos de Orçamento de Faturamento

Ao acessar a tela, você conseguirá listar todas os Tipos de Orçamento de Faturamento ou filtrá-los de acordo com os filtros disponíveis na tela, para editá-los clique no botão Editar.

Exclusão Tipos de Orçamento de Faturamento

Você também conseguirá fazer a exclusão de um Tipos de Orçamento de Faturamento clicando em Excluir. Caso necessário poderá restaurar o registro excluído, clicando em Restaurar Registro, na lista de Série, lembrando que essa opção está disponível apenas para usuários configurados como Administradores.
