Integração API de Cobrança Sicoob

Neste artigo te mostraremos o passo a passo para habilitar no M8 a integração com API de cobrança do Sicoob, esse processo permitirá que uma maior agilidade no processo de cobrança, assim como um maior controle das movimentações financeiras da sua empresa.

Financeiro > CADASTROS > CADASTROS > Lista Cadastro de Convênios Bancários para Boletos

Após aberta a lista de Convênios, edite o convênio Sicoob configurado e siga as seguinte etapas:

1 - Para iniciar o processo de integração da API da Cobrança Sicoob, o cliente deverá contratar o serviço de APIs disponivilizado no Portal do Sicoob, disponível em Meus Aplicativos > APIs. 2 - No portal desenvolvedor Sicoob, obter as informações para preencher os dados de Configuração Boleto Eletrônico no cadastro Convênio Bancário.
3 - Seguir padrão (nome=valor; ) na mesma linha sem espaçamentos conforme exemplo abaixo:

  • Cliente_id: Código da sua empresa na API do Sicoob.
  • Número Contrato: Número do convênio/contrato com o banco.

É importante que, após feitas as configurações, seja efetuada a geração de um boleto para teste. Pode ocorrer uma falha; caso isso aconteça, acesse o aplicativo do banco e localize a área de transações pendentes. Nessa área, deve ser autorizada a utilização da API para cobrança.
Dessa forma, quando as Notas Fiscais forem faturadas com geração de boleto, este será gerado pelo Banco Sicoob e, através da comunicação com a API, poderá ser impresso no sistema, assim como ao regerar os boletos. Outro ponto importante é que esta integração dispensa a importação de arquivos de retorno de pagamento para efetuar a baixa de títulos, pois essa integração também é feita diretamente pela API. Basta realizar a pesquisa dos títulos e executar o comando para finalizar a baixa dos títulos correspondentes.
