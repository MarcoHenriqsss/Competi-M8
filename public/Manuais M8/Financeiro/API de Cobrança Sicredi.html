Integração API de Cobrança Sicredi

Neste artigo te mostraremos o passo a passo para habilitar no M8 a integração com API de cobrança do Sicredi, esse processo permitirá que uma maior agilidade no processo de cobrança, assim como um maior controle das movimentações financeiras da sua empresa.

Financeiro > CADASTROS > CADASTROS > Lista Cadastro de Convênios Bancários para Boletos

Após aberta a lista de Convênios, edite o convênio Sicredi configurado e siga as seguinte etapas:

1 - Para iniciar o processo de integração da API da Cobrança Sicredi, o cliente deve contratar o produto "Cobrança" com a pessoa Gerente de conta e optar pela modalidade API (Cobrança Online). 2 - Após obter dados acesso, entrar em https://developer.sicredi.com.br/api-portal/pt-br 3 - No portal desenvolvedor Sicredi, obter as informações para preencher os dados de Configuração Boleto Eletrônico no cadastro Convênio Bancário.
4 - Seguir padrão (nome=valor; ) na mesma linha sem espaçamentos conforme exemplo abaixo:

  • Username: Beneficiário + Cooperativa.
  • Password: Código de acesso gerado no Internet Banking (gerente de conta deve auxiliar na geração desse campo).
  • Cooperativa: Código da cooperativa.
  • Posto: Código da agência.
  • X-api-key: Token de acesso criado no chamado do portal.

Após feita essa configuração, quando faturadas as Notas Fiscais com geração de boleto, este boleto será gerado pelo Banco Sicredi e pela comunicação com a API poderá ser feita a impressão no sistema, assim como ao regerar os boletos. Outro ponto importante, é que esta integração dispensa a importação de arquivos retorno de pagamento para efetuar a baixa de títulos, pois essa integração também é feita diretamente pela API.
