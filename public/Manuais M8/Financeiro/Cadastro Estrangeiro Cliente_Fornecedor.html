Cadastro de Cliente/Fornecedor Estrangeiro

Para realizarmos o cadastro de estrangeiro, pode usar como embasamento o artigo Cadastro Cliente ou Cadastro Fornecedor, porém, alguns pontos devem ser levados em consideração, conforme descritos a seguir.

Cadastro Tipo Pessoa

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Tipos de Pessoas

Crie um novo Tipo de pessoa que indique no campo Tipo que se trata de uma pessoa estrangeira.

Cadastro País

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Países

  • País: Informe o nome do país de origem do cliente/fornecedor;
  • Bacen: Preencha com o código do Banco Central referente ao país.

Cadastro Estado

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Estados

  • País: Selecione o país cadastrado no passo anterior;
  • Estado: Informe o nome do estado ou região do cliente/fornecedor.
  • UF: Use a sigla "EX" (de estrangeiro);
  • Os demais campos podem ser preenchidos conforme necessário.

Cadastro Município

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Municípios

  • Estado: Selecione o estado criado no passo anterior;
  • Comarca: Preenchimento opcional;
  • Município: Informe o nome do município do cliente/fornecedor;
  • CEP: Utilize o formato 99999-999;
  • Estrangeiro: Marque a opção "Sim";
  • IBGE: Pode ser preenchido com 9999999, especificamente com sete dígitos;
  • Os demais campos são opcionais.

Cadastro Bairro

Configurações > CADASTROS > CADASTROS > Lista Cadastro de Bairros

  • Município: Informe o município cadastrado anteriormente;
  • Bairro: Digite o nome do bairro do cliente/fornecedor.

Cadastro Cliente

Faturamento > CADASTROS > CADASTROS > Lista Cadastro de Clientes

  • Tipo Pessoa: Selecione o tipo de pessoa cadastrado no primeiro passo;
  • CPF/CNPJ: Para clientes estrangeiros, utilize o padrão 00.000.000/0000-00, pois não possuem CNPJ.

Preencha conforme as informações do cliente;
Caso não haja dados de inscrição, escreva "ISENTO" nos respectivos campos; Informe que não há contribuição nos campos abaixo das inscrições; Endereço e Informações Complementares

  • CEP: Utilize o 99999-999;
  • Logradouro: Informe o endereço do cliente/fornecedor ou use "S/L" (sem logradouro);
  • Número: Informe o número, se existir, ou use "S/N" (sem número);
  • Complemento/Letra: Preenchimento opcional;
  • Município e Bairro: Selecione os dados cadastrados anteriormente.

Os demais campos podem ser preenchidos conforme a mesma lógica usada para clientes e fornecedores nacionais. A diferença principal está nos campos de país, estado, município e CNPJ, que precisam ser adaptados para o contexto internacional.
