Cadastro de Convênios Bancários para Boletos

O Cadastro de Convênio Bancário desempenha um papel crucial ao automatizar e organizar transações financeiras, garantindo eficiência e controle.

Financeiro > CADASTROS > CADASTROS > Lista Cadastro de Convênios Bancários para Boletos

Inclusão de Convênio Bancário

Para incluir um novo Convênio Bancário você deverá clicar na opção no canto superior esquerdo da tela.

Cabeçalho

  • Código: Código sequencial de identificação gerado automaticamente pelo sistema.
  • Estabelecimento: Deverá informar o estabelecimento que o convênio pertence.
  • Banco: Selecione o Banco referente a este convênio.
  • Cnab: Seleciona o CNAB utilizado para esse convênio.
  • Nome: Deverá informar um nome de identificação para o convênio.
  • Conta Bancária: Informe a conta bancária referente este convênio.
  • Nosso Número: Deverá informar o nosso número, se você não possuir uma relação sobre as numerações já utilizadas, é importante solicitar ao banco qual o último “Nosso Número” utilizado, e prosseguir a emissão a partir dele. Esse número será atualizado automaticamente conforme a emissão de boletos com este convênio.
  • Número Convênio: Deverá informar o número do convênio (numeração disponibilizada pelo banco).
  • Tipo Documento: Será o Tipo Documento utilizado para geração de remessa de acordo com layout específico de cada Banco.
  • Carteira: Deverá informar uma carteira para a cobrança dos boletos.
  • Espécie: Informe a espécie de título que será utilizado naquele convênio.
  • Primeira Instituição: Poderá informar uma primeira instrução para os boletos gerados com esse convênio.
  • Segunda Instituição: Poderá informar uma segunda instrução para os boletos gerados com esse convênio.
  • Modalidade: Poderá informar uma modalidade que será utilizada naquele convênio.
  • Padrão Layout: Informação utilizada para geração de Remessa de acordo com layout específico de cada Banco.
  • Variação: Será o código de variação da conta bancário, este é repassado pela agência.
  • Dias Protesto/Devolução: Poderá informar quantos dias após o vencimento o título irá para protesto.
  • Dias Cobrar Multa: Poderá informar quantos dias após o vencimento do título será aplicado valor de multa sobre os títulos.
  • Participante: Será informado o participante dos boletos de acordo com layout específico de cada Banco.
  • Última Remessa: Será preenchido automaticamente conforme forem enviadas as remessas desse convênio.

  • Aceite: Indica o reconhecimento formal (assinatura no documento) do pagador do título. Quando marcado o pagador deverá assinar o título e quando desmarcado (padrão) o pagador não assina o título.
  • Exibir Todas Filiais: Quando marcado o convênio poderá ser utilizado por todas as empresas daquele estabelecimento.
  • Convênio Padrão: Quando marcado o convênio poderá ser utilizado por todos os estabelecimentos da empresa.
  • Exibir Documento/Parcela: Quando marcado, será exibido na impressão do boleto o número de documento do título e a parcela referente aquele determinado boleto.
  • Cód. Juros/Multa: Deverá informar o Cód. de cobrança de Juros/Multa.
    • 1 - Valor dia.
    • 2 - Taxa Mensal.
  • % Multa: Poderá informar uma % de multa para ser cobrada nos boletos gerados com esse convênio.
  • % Juros: Poderá informar uma % de juros para serem cobrados nos boletos gerados com esse convênio.
  • Comando Título Juro/Multa: Poderá adicionar nesse campo os comandos de retorno bancário referente ao protesto em cartório efetuado pelo banco.
  • Convênio Líder: Poderá informar o número do convênio líder.
  • Posto: Poderá informar o posto de atendimento bancário do convênio líder.
  • Cooperativa: Poderá informar a Cooperativa do convênio líder.
  • Cnpj Cooperativa: Poderá informar o CNPJ da Cooperativa do convênio líder.
  • Diretório Remessa: pasta para salvar o arquivo
  • Instruções Livre Boleto: Poderá informar instruções livres para os boletos emitidos com esse convênio.
