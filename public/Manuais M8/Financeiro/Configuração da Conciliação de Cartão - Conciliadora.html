    • Como funciona a Conciliação de Cartão

    A funcionalidade de Conciliação de Cartão permite integrar as vendas realizadas via cartão com a conciliadora, possibilitando o acompanhamento dos pagamentos e a baixa automática dos títulos conforme a confirmação recebida. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo, o processo funciona em 4 etapas:

    1. Configuração da integração

    Para realizar a integração da Conciliadora de Cartões, deverá acessar:

    CAMINHO: Configurações > Cadastros > Cadastro de Estabelecimentos > Configuração Conciliadora Cartão

    Para fazer a configuração da conciliadora clique na opção no canto direito.

    • Integradora: Conciliadora
    • Token de acesso: Chave de autenticação utilizada na integração
    • Código da empresa: Identificador da empresa na Conciliadora
    • Senha de acesso: Senha utilizada para comunicação com a integradora

    Essa configuração é obrigatória para permitir o envio e retorno das informações entre o sistema e a Conciliadora.

    2. Cadastros para realizar na Integração com a Conciliadora

    Cadastro de Bandeiras de Cartão

    CAMINHO: Financeiro > CADASTROS > CADASTROS > Lista Cadastro de Bandeiras de Cartão

    Para incluir uma nova Cadastro de Bandeiras de Cartão clique na opção no canto direito.

    deverá ser informado:

    • Código Integração: Código utilizado para identificar as bandeiras de cartões utilizadas na integração.

    Após preencher os campos, clique em para que novo Cadastro de Bandeiras de Cartão seja salvo com sucesso.

    Cadastro de Operadoras de Cartão
    Acessando:

    CAMINHO: Financeiro > Cadastros > Cadastro de Operadoras de Cartão

    Para incluir um novo cadastro das Operadoras de Cartões clique na opção no canto direito.

    deverá ser informado:

    • Código Integração: Código utilizado para identificar as bandeiras de cartões utilizadas na integração.

    Após preencher os campos, clique em para que novo cadastro das Operadoras de Cartões seja salvo com sucesso.

    Cadastro de Meios de Captura

    Acessando:

    CAMINHO: Financeiro > Cadastros > Cadastro de Meios Captura Cartão

    Para incluir um novo cadastro Meios Captura Cartão de clique na opção no canto direito.

    deverá ser informado:

    • Código Integração: Código utilizado para identificar os meios de captura das transações de cartão.

    Após preencher os campos, clique em para que o novo cadastro Meios Captura Cartão seja salvo com sucesso.

    Cadastro de Condições de Pagamento

    Acessando:

    CAMINHO Financeiro > Cadastros > Cadastro de Condições de Pagamento

    Para incluir um novo Cadastro de Meios de Pagamento clique na opção no canto direito.

    foram adicionados os campos:

    • Bandeira Cartão: Identifica a bandeira utilizada na transação.
    • Meio Captura Cartão: Identifica o meio de captura utilizado na transação.

    Esses campos serão utilizados para geração das parcelas integradas à Conciliadora.

    Após preencher os campos, clique em para que o novo cadastro Meios de pagamento seja salvo com sucesso.

    3. Integração via API - Adiantamento de Cliente

    Integração via API - Adiantamento de Cliente

    CAMINHO: Financeiro > CADASTROS > CADASTROS > Lista Cadastro de Condições de Pagamento

    Adicionados os campos de Bandeira Cartão e Meios Captura Cartão, para realizar a vinculação para geração das parcelas que serão integradas na Conciliadora.

    Para realizar a vinculação clique na opção no canto direito.

    EndPoint: Adiantamento de Cliente. Responsável pelo envio e integração das informações de adiantamento de cliente no módulo financeiro.
    URL da API: https://api.integra.m8sistemas.com.br/v1/financeiro/adiantamentocliente
    Campos utilizados na integração:
    pessoaCartaoId: Identificador do cadastro da operadora/cartão vinculado à transação. condicaoPagamentoId: Identificador da condição de pagamento utilizada na transação. autenticacao: Código de autenticação retornado pela operadora do cartão. autorizacaoCartao: Código de autorização da transação do cartão. nsu: Número Sequencial Único da transação.
    nsuHost: Número identificador da transação gerado pela adquirente/host. dataTransacao: Data em que a transação foi realizada. numeroParcelas: Quantidade de parcelas da transação.

    Após preencher os campos, clique em para que a vinculação seja salva com sucesso.

    Dados do Cartão no Adiantamento

    No cadastro:

    CAMINHO: Financeiro > Movimento > Adiantamento > Adiantamento de Clientes

    No cadastro de Adiantamento de Cliente, adicionamos a aba de Dados Cartão, onde irá armazenar as informações da transação do cartão vinda pela API.

    Para realizar a edição clique na opção no canto direito.

    Dados Cartão: Essa aba é responsável por armazenar as informações da transação recebidas pela API.

    Informações utilizadas
    Pessoa Cartão
    Condição de Pagamento
    Autorização Cartão
    NSU
    Data Transação

    Ao processar o adiantamento, será gerado automaticamente um lançamento no Contas a Receber, criando as parcelas conforme os Dados do Cartão informados.

    4.Conciliação de Cartão

    Para efetuar a integração com a Conciliadora, realizando o envio das vendas e a baixa dos pagamentos recebidos, foram criadas as seguintes telas:
    Enviar Vendas
    Buscar Pagamentos Confirmados

    Enviar Vendas
    Acesse:

    CAMINHO: Financeiro > Movimento > Conciliação Cartão > Enviar Ven das

    Nesta tela serão listadas somente as parcelas que possuírem:

    • NSU preenchido
    • Autorização do Cartão preenchida
    Após o envio dos títulos, as informações poderão levar até 24 horas para serem exibidas no painel da Conciliadora.

    Buscar Pagamentos Confirmados
    Acesse:

    CAMINHO: Financeiro > Movimento > Conciliação Cartão > Buscar Pagamentos Confirmados

    Nesta tela o sistema irá consultar os lançamentos de vendas realizadas no cartão e integradas à Conciliadora.

    A localização dos registros poderá ocorrer através de:

    • Autorização do Cartão
    • NSU
    • ID da parcela

    Caso os lançamentos sejam identificados, através da opção:

    • Baixar Títulos

    será possível efetuar a baixa automática do lançamento no sistema.
