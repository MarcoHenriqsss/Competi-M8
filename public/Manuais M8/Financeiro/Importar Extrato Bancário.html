Importar Extrato Bancário

Nessa rotina você conseguirá realizar a importação do extrato bancário referente a sua Instituição Financeira contendo todas as movimentações realizadas através da mesma.

Caminho de Acesso: Financeiro > ARQUIVOS > ARQUIVOS IMPORTAÇÕES > Importar Extrato Bancário

Filtros

  • Extrato Eletrônico: Ao marcar, o sistema irá comunicar com a API do banco para consultar de forma automática as movimentações do extrato bancário, sem necessidade de importar um arquivo.OFX
  • Arquivo: Aqui você selecionará o arquivo referente ao extrato bancário no formato ".OFX". Para selecionar o arquivo basta clicar no botão.
  • Layout: Nesse campo você selecionará o layout referente ao banco do extrato, nesse campo, cada banco possuí seu layout específico.

Após a seleção do arquivo, deverá clicar no botão para que o sistema leia o arquivo e identifique toda a movimentação bancária.

Após a leitura do arquivo, o sistema apresentará em tela a movimentação bancária, separando por Crédito e Débito, nessa tela verá também os Títulos liberados para importação, segundo o ícone.

Para finalizar a importação do extrato, basta clicar no botão.
