Importar Folha de Pagamentos Financeiro

O processo de importar folha de pagamentos no financeiro, é um processo disponibilizado pelo M8 para importar o financeiro da folha de pagamento dos funcionários da sua empresa de acordo com o programa utilizado para fazer o controle dessas folhas.

Financeiro > ARQUIVOS > ARQUIVOS IMPORTAÇÕES > Importar Folha de Pagamentos

Filtros

  • Arquivo: Campo disponível para que selecione do arquivo de folha de pagamento.
  • Layout: Layout do arquivo que será importado, de acordo com o sistema utilizada para geração do arquivo selecionado acima.
  • Destino: Tela do financeiro onde serão gerados os lançamentos referente a folha.
  • Data Lançamento: Data de lançamento dos valores referente a folha no sistema.
  • Competência: Informe a Competência que serão gerados os lançamentos no sistema.
  • Plano de Contas Financeiro: Plano financeiro que será utilizado para o lançamento no sistema.
  • Espécie: Espécie do financeiro que será utilizado no lançamento no sistema.
  • Condição Pagamento: Condição de pagamento que será utilizada para o lançamento no sistema.
  • Conta Débito: Conta débito que será utilizada no lançamento no sistema.
  • Conta Crédito: Conta crédito que será utilizada no lançamento no sistema.
  • Histórico: Histórico que será utilziado no lançamento no sistema.
  • Centro de Custo: Centro de custo que será utilziado para o lançamento no sistema.
  • Projeto: Projeto que ficará vinculado ao lançamento no sistema.

Após preencher essas informações, poderá clicar no botão pesquisar e assim serão exibidos os lançamentos do arquivo selecionado no tabelamento abaixo. Nesta listagem você poderá fazer a conferencia dos dados exibidos, após isso clique em dessa forma os lançamentos serão concretizados no sistema.
