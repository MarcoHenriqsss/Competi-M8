Lista Cadastro de Bandeira de Cartão

O Cadastro de Bandeira de Cartão é realizado para identificar a Bandeira do Cartão nas Condições de Pagamento utilizadas como Cartão de Débito/ Crédito.

Caminho de Acesso: Financeiro > CADASTROS > CADASTROS > Lista Cadastro de Bandeiras de Cartão

Inclusão de Bandeira de Cartão

Para incluir um novo cadastro de Bandeira de Cartão deverá no canto superior esquerdo para gerar um novo Registro.

Cabeçalho

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Nome: Estabelecerá uma descrição para a bandeira de Cartão.

Após preencher todos os campos, clique em, para que o cadastro seja finalizado.

Edição de Cadastro Bandeira de Cartão

Ao acessar a tela, você conseguirá listar todos os Cadastros Bandeira de Cartão ou filtrá-los de acordo com os filtros disponíveis na tela, para editá-los clique no botão Editar.

Exclusão de Cadastro de Bandeira de Cartão

Você também conseguirá fazer a exclusão de um Cadastro Bandeira de Cartão, clicando em Excluir. Ao excluir esse Cadastro ele não poderá ser utilizado nas rotinas do sistema. Caso necessário, você poderá restaurar o registro excluído, clicando em Restaurar Registro na lista de Bandeira de Cartão, lembrando que essa opção é exibida para usuários configurados como Administrados.
