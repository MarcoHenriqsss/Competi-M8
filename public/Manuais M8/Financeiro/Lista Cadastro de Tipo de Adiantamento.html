Lista Cadastro de Tipo de Adiantamento

O Cadastro de Tipo de Adiantamento é realizado para parametrizar configurações utilizadas na emissão de adiantamentos no sistema. Permitirá cadastrar um tipo específico em que poderá preencher os campos Tipo Cliente, Moeda, Meio de Pagamento, Plano de Contas Financeiro, Conta Destino, Histórico Contábil e Espécie, dessa forma ao selecionar o Tipo Adiantamento o sistema preencherá automaticamente os campos citados no adiantamento.

Caminho de Acesso: Financeiro > CADASTROS > CADASTROS > Lista Cadastro de Tipo de Adiantamento

Inclusão de Tipo de Adiantamento

Para incluir um novo Tipo de Adiantamento deverá no canto superior esquerdo para gerar um novo Registro.

Cabeçalho

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Nome: Estabelecerá uma descrição para o Tipo de Adiantamento.
  • Tipo de adiantamento: Definirá se esse tipo de Adiantamento será para de Clientes ou Fornecedores.
  • Moeda: Definirá a moeda de negociação dos Adiantamentos que tiverem esse Tipo informado.
  • Meio de Pagamento Definirá o Meio de Pagamento para os Adiantamentos gerados.
  • Plano de contas Financeiro: Estabelecerá o Plano de Contas Financeiro para os Adiantamentos gerados.
  • Conta Destino: Deverá informar a Conta Contábil de Caixa/Banco que movimentará o valor, como Destino para os adiantamentos gerados.
  • Histórico
    Contábil: Campo onde você informará o texto padrão como histórico das contabilizações, exibidos em relatórios e movimentações desse adiantamento.
  • Espécie: Qual a espécie do documento que está sendo lançado.

Após preencher todos os campos, clique em, para que o cadastro seja finalizado. Ao realizar um lançamento de Adiantamento, sendo de Cliente ou Fornecedor, de acordo com a configuração feita, poderá vincular o Tipo de Adiantamento as informações inseridas serão preenchidas automaticamente no Adiantamento.

Edição de Cadastro de Tipo de Adiantamento

Ao acessar a tela, você conseguirá listar todos os Cadastros Tipo de Adiantamento ou filtrá-los de acordo com os filtros disponíveis na tela, para editá-los clique no botão Editar.

Exclusão de Cadastro de Tipo de Adiantamento

Ao excluir esse Cadastro ele não poderá ser utilizado nas rotinas do sistema. Caso necessário, você poderá restaurar o registro excluído, clicando em Restaurar Registro

Você também conseguirá fazer a exclusão de um Cadastro Tipo de Adiantamento, clicando em Excluir. na lista de Tipos de Adiantamentos, lembrando que essa opção é exibida para usuários configurados como Administrados.
