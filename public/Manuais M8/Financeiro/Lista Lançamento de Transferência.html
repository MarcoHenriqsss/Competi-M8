Lista Lançamento de Transferência

O processo de Transferência é utilizado para movimentar valores entre contas ou caixas dentro do sistema, permitindo o controle adequado dos recursos financeiros. Nessa rotina, os valores são transferidos de uma conta/caixa de origem para uma conta/caixa de destino, ambas configuradas na modalidade Conta Caixa. Essa funcionalidade garante a correta movimentação financeira, mantendo a rastreabilidade e a integridade dos registros contábeis. A seguir, o passo a passo de como realizar esse processo de forma simples e segura.

Caminho de acesso: Módulo Financeiro -> MOVIMENTO-> CAIXA-> Lista lançamento Transferência

Para incluir uma nova Transferência de Caixa clique na opção no canto superior esquerdo. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

Cabeçalho

Onde:

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Estabelecimento: Determinará a qual Estabelecimento essa Transferência pertencerá.
  • Pessoa: Definirá qual cliente/fornecedor será filtrado para vincular na movimentação.
  • Documento: Número de documento atrelado a este lançamento.
  • Lançamento: Data que ficará registrado.
  • Valor: Valor da Transferência.
  • Conta financeira: Esse campo deverá ser informado qual plano de contas financeira a movimentação ficará relacionada.
  • Conta Origem: Deverá ser informado a conta Caixa/banco para ser a Origem do valor, o lançamento registra como débito.
  • Conta Destino: Deverá informar a conta Caixa/Banco que receberá o valor como Destino. O lançamento no caixa/banco fica como crédito.
  • Histórico Contábil: Descrição do fato da transferência para mostrar nos relatórios.
  • Projeto: Este campo possibilitará vincular o lançamento a um Projeto.
  • Item Projeto: Este campo possibilitará vincular o lançamento a uma etapa do Projeto.
  • Processo Importação: Informar o Processo de importação.
  • Complemento: Campo para inserir alguma descrição adicional, caso necessário.
  • Observação: Caso o lançamento tenha alguma situação específica, essa deve ser preenchida nas observações.

Após preencher os campos, clique em para que a transferência seja lançada na listagem, dessa forma você poderá lançar um novo item, assim como editá-los.

Centro de custo

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Centro de Custo: Caso necessário, nesse campo você informará o centro de custo que o lançamento fará parte.
  • Plano de Contas Financeiro: Esse campo poderá ser informado qual conta financeira ficará relacionada.
  • % Percentual: Qual o percentual em relação ao valor total da transferência de caixa será calculado no centro de custo.
  • Valor: Qual o valor do centro de custo será lançado em relação ao lançamento de transferência.
  • Complemento: Campo de descrição livre para informações complementares referente a transferência.

Após preencher os campos clicar em.

Contabilizações

Nesta aba ficam listadas as contabilizações de Débito e Crédito, vinculadas a esse lançamento de transferência.

Anexos

A aba anexos permitirá que você insira imagens ou arquivos, estes ficarão vinculados a esta transferência de caixa. O anexo poderá ser feito a partir da leitura do QR Code, ou anexo direto de arquivos.

  • Cód.: Código interno gerado automaticamente pelo sistema.
  • Fotos pelo Celular: Através da leitura do QR-Code com um Smartfone, o sistema direciona o usuário para um link com essa transferência, onde todos os arquivos e imagens que o usuário incluir por esse link irá aparecer na grid de anexos da transferência.
  • Descrição: Campo onde será informado nome para identificação do anexo.
  • Arquivo: Campo onde será possível selecionar o arquivo desejado.

Após preencher os campos, clique em para que o item seja lançado na listagem abaixo, dessa forma você poderá lançar um novo item, assim como editá-los.

Ações

  • Copiar Registro: Esta rotina irá copiar o lançamento de transferência, com um novo código de registro.
  • Imprimir Espelho: Nessa opção conseguirá gerar a impressão do Espelho deste lançamento.

Edição de Cadastro de Cliente

Ao acessar a tela, você conseguirá listar todas aos Lançamentos de Transferência ou filtrá-las conforme os filtros disponíveis na tela, para editá-las clique no botão Editar.

Exclusão de Cadastro de Cliente

Ao excluir esse Cadastro ele não poderá ser utilizado nas rotinas do sistema. Caso necessário, e possua as permissões necessárias, poderá restaurar o registro excluído, clicando em Restaurar Registro

Você também conseguirá fazer a exclusão de um Lançamento de Entrada, clicando em Excluir.

na tela de Lançamentos de Transferência, lembrando que essa opção é exibida para usuários configurados como Administrados.
