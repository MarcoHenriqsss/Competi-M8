Lista Lançamentos de Extrato

O processo de lançamento de Extrato é utilizado para adicionar registros e listar os lançados importados pelo arquivo OFX, para efetuar a Conciliação Bancária.

Módulo Financeiro > MOVIMENTO > CONCILIAÇÃO BANCÁRIA > Lista Lançamentos de Extrato

Inclusão de Cadastro de Extrato Bancário

Para lançar um cadastro de Extrato Bancário clique na opção no canto superior esquerdo.

Cabeçalho

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Crédito/Débito: Você poderá definir se esse lançamento é um débito ou um crédito.
  • Data Lançamento: Data de registrado da movimentação.
  • Conta Contábil: Neste campo deverá ser informada a Conta Contábil da movimentação.
  • Identificador: Poderá informar número identificador do registro conforme exibido no Extrato Bancário
  • Descrição: Poderá informar a descrição referente a movimentação desse registro conforme exibido no Extrato bancário
  • Valor: Deverá informar o Valor que será lançado.

Após preencher os campos, clique em para que o registro seja lançado na listagem, dessa forma você poderá lançar um novo item, assim como editá-los. Além do lançamento manual dos registros do extrato bancário o sistema disponibiliza uma rotina, no caminho Financeiro > ARQUIVOS > ARQUIVOS IMPORTAÇÕES > Importar Extrato Bancário, essa permite que seja importado o arquivo do extrato para o sistema, dessa forma os lançamentos serão feitos automaticamente, esses serão exibidos na Lista Extrato Bancário e também na tela de Conciliação Bancária.

Lista Registros

Poderá visualizar os registros lançados manualmente e os lançados pelo arquivo do Extrato Bancário, poderá aplicar filtros para buscar os registros por: Código, Data lançamento, Cod. Conta contábil, Documento, Descrição e Valor.

Editar Registros de Extrato Bancário

Ao acessar a tela da lista de Extrato bancário, você poderá filtrar os lançamentos para localizar informações específicas. Caso seja necessário, você também poderá editar um lançamento selecionado clicando em Editar.

Excluir registros de Extrato Bancário

Poderá excluir os registros do Extrato bancário, caso seja necessário. Ao excluir o registro do extrato bancário não será possível recuperá-lo e também não poderá utilizá-lo em nenhuma rotina do sistema.
