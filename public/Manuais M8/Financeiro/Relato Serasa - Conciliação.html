Relato Serasa - Conciliação

O Relato Serasa - Conciliação permite que seja feita a conciliação entre os dados do sistema enviado no Relato Serasa e os valores atualizado no arquivo de retorno gerado pelo Serasa.

Financeiro > MOVIMENTO > MOVIMENTO > Relato Serasa - Conciliação

  • Arquivo: Nesse campo você deverá selecionar o arquivo retornado pelo Serasa.

Após escolher o arquivo, clique em. O Sistema irá exibir logo abaixo a lista de títulos presentes do arquivo.

Posteriormente, clique em, o sistema irá comparar os dois arquivos, validar se houveram pagamentos registrados pelo Serasa no arquivo de retorno e dessa forma gerar um novo arquivo de Relato Serasa atualizado, somente com o saldo e parcelas restantes. Dessa forma o novo arquivo deverá ser enviado ao Serasa novamente.
