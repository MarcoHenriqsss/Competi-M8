Renegociação de Títulos à Receber

A Renegociação de Títulos a Receber servirá para ajustar títulos em inadimplência de um cliente, você poderá alterar a número de parcelas, valores de juros e multa, entre outras informações. Essa rotina também poderá ser utilizada para um agrupamento de vários Títulos em apenas um, dessa forma gerando um único boleto por exemplo.

Financeiro > MOVIMENTO > MOVIMENTO > Renegociação de Títulos a Receber

Inclusão de Renegociação de Títulos à Receber

Para incluir uma nova Renegociação de Títulos à Receber o clique na opção no canto superior esquerdo.

Cabeçalho

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Situação: Informará a situação em que está a renegociação.
    • Pendente: Quando ainda permite alteração.
    • Processado: Quando já foi finalizado/renegociado.
    • Cancelado: Quando foi cancelado pelo usuário.
  • Emissão: Deverá ser preenchido com a data de emissão dessa renegociação. O sistema sugerirá a data atual de lançamento do cadastro.
  • Entrada: Deverá ser preenchido com a data de entrada do título dessa renegociação. O sistema sugere a data atual de lançamento do cadastro.
  • Empresa: Nesse campo você definirá a empresa de posse do título renegociado.
  • Pessoa: Nesse campo você informará o cliente do título.
  • Grupo Econômico: Aqui você preencherá o grupo econômico do cliente em questão.
  • Modelo Contrato: Neste campo poderá ser informado um modelo de contrato firmado com o cliente da renegociação.
  • Moeda: Definirá a moeda de negociação.
  • Observações: Campo destina a informações de descrição livre.

Após o preenchimento dos campos do cabeçalho será aberto na tela um modal onde você deverá filtrar e selecionar os títulos a serem renegociados.

Nessa tela você poderá filtrar os títulos por número de documento ou data de vencimento, depois clique em

para exibir os títulos. Após selecionar o títulos desejados clique em para finalizar o processo de seleção.

Títulos Anteriores

Exibirá uma lista com os títulos selecionados anteriormente, que serão renegociados, no final da tela o valor total dos títulos.

Finalizar

  • Código: Código sequencial gerado automaticamente pelo sistema.
  • Utilizar %: Esta opção servirá para escolher se os juros e multas serão informados em porcentagem ou valor.

Quando marcado a opção Utilizar % você deverá preencher os campos:

  • % Juro: Percentual a ser cobrado de juro na renegociação. Será obrigatório preenchimento quando os títulos anteriores estivem vencidos.
  • % Multa: Percentual a ser cobrado de multa na renegociação. Será obrigatório preenchimento quando os títulos anteriores estivem vencidos.

Quando desmarcado a opção Utilizar %, você deverá preencher os campos:

  • Valor Juro: Valor a ser cobrado de juro na renegociação. Será obrigatório preenchimento quando os títulos anteriores estivem vencidos.
  • Valor Multa: Valor a ser cobrado de multa na renegociação. Será obrigatório preenchimento quando os títulos anteriores estivem vencidos.
  • Condição Pagamento: Definirá a condição de pagamento para o novo título a ser gerado.
  • Plano de Contas Financeiro: Estabelecerá o plano de contas financeiro para o novo título a ser gerado.
  • Moeda: Definirá a moeda de negociação do título.
  • Espécie: Informe a espécie do documento a ser gerado.
  • Portador: Será a pessoa ou instituição responsável pela cobrança do título.
  • Vendedor: Nesse campo você informará o vendedor.

Após preencher todos as informações necessárias clique em. Para finalizar a renegociação você deverá clicar na opção Gerar Renegociação no menu Ações. Dessa forma será gerado o títulos renegociado, este será exibido na aba Título Gerado.

Título Gerado

Essa aba será utilizada para fins de conferência.

  • Código: Será exibido o código sequencial gerado automaticamente pelo sistema.
    • Abrir Lançamento: Clique no ícone para abrir o lançamento gerado.
  • Condição Pagamento: Trará a condição de pagamento usado para gerar o novo título.
  • Plano de Contas Financeiro: Trará o plano financeiro usado para gerar o novo título.
  • Moeda: Exibirá a Moeda que foi usado para gerar o novo título.
  • Documento: Mostrará o número do documento gerado. O Sistema irá criar um número para o título e irá usar a letra 'R' para identificar que este foi gerado por renegociação.
    • Exemplo: R0123
  • Espécie: Trará a espécie do documento usado para gerar o novo título.
  • Emissão: Exibirá a data de emissão usada para gerar o novo título.
  • Entrada: Mostrará a data que foi usado para gerar o novo título.
  • Pessoa: Trará a Pessoa utilizada para gerar o novo título.
  • Valor: Mostrará o Valor Total do novo título.
  • Complemento: Exibirá a informação dos títulos anteriores renegociados.
  • Observação: Trará uma informação padrão, informando que esse título foi renegociado (DOCUMENTO RENEGOCIADO REFERENTE A RENEGOCIAÇÃO DE TÍTULOS Nr.: 0123)

Anexos

A aba Anexos permitirá que você anexe imagens ou arquivos, estes ficarão vinculados a esta renegociação. O anexo poderá ser feito a partir da leitura do QR Code, ou anexo direto de arquivos.

  • Código: Código interno gerado automaticamente pelo sistema.
  • Fotos pelo Celular: Através da leitura do QR-Code com um Smartphone, o sistema direciona o usuário para um link com essa Renegociação de Títulos a Receber onde todos os arquivos e imagens que o usuário incluir por esse link irá aparecer na grid de anexos da Renegociação.
  • Descrição: Campo onde será informado nome para identificação do anexo.
  • Arquivo: Campo onde será possível selecionar o arquivo desejado.

Após preencher os campos, clique em para que o item seja lançado na listagem abaixo, dessa forma você poderá lançar um novo item, assim como editá-los.

Contabilizações Juros/Multa

Na aba contabilizações (juros/multa), o sistema trará a informação das contas contábeis movimentadas, conforme configuração.

Ações

  • Gerar Renegociação: Essa funcionalidade finalizará o processo, gerando o título final renegociado.
  • Adicionar Títulos à Receber: Essa opção servirá para incluir títulos anteriores que serão renegociados.
  • Simular Renegociação à Receber: Essa opção exibirá uma simulação do título final renegociado antes de Gerar a Renegociação.
  • Cancelar Renegociação: Essa opção cancelará o título renegociado.

Edição Renegociação de Títulos a Receber

Ao acessar a tela, você conseguirá listar todas as Renegociação de Títulos a Receber ou filtrá-las de acordo com os filtros disponíveis na tela, para editá-las clique no botão Editar.

Exclusão Renegociação de Títulos a Receber

Você também conseguirá fazer a exclusão de uma Renegociação de Títulos a Receber que esteja com status Pendente clicado em Excluir. Ao excluir essa Renegociação você não conseguirá recuperá-lo e também não poderá utilizá-la em nenhuma rotina do sistema.
