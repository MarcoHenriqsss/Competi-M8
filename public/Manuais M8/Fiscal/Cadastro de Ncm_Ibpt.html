Cadastro de Ncm/Ibpt

Hoje no M8 as tabelas de Ncm/Ibpt são atualizadas conforme notas técnicas do SEFAZ, porém caso haja algum NCM específico que foi cadastrado ou alterado sem uma nota técnica, existe a possibilidade de cadastrá-lo ou editá-lo de forma manual.

Fiscal > CADASTROS > CADASTROS > Lista Cadastro de Ncm/Ibpt

Inclusão de Cadastro de Ncm/Ibpt

Para incluir um novo NCM clique na opção no canto superior esquerdo. Para te auxiliar neste cadastro, criamos esse artigo com a descrição detalhada de todos os campos, segue abaixo:

Cabeçalho

  • Código: Código de identificação interna que será gerado automaticamente pelo sistema.
  • NCM: Campo destinado ao código do NCM.
  • EX/Tipi: Exceção para cada código de NCM. Caso possua o mesmo NCM cadastrado mais de uma vez, nesse campo você deverá configurar cada particularidade de sua exceção.
  • Cód. Benefício Fiscal: Caso queira fazer o controle de Benefícios Fiscais por NCM, poderá preenche-lo nesse campo, de acordo com as regras de tributação da sua empresa.
  • % IPI: Alíquota do IPI específica para esse NCM.
  • Unidade Exportação: Configuração válida para Notas Fiscais de Exportação. Caso preencha esse campo, ao utilizá-lo em uma Nota de Exportação, o sistema irá inserir essa informação na tag uTrib do XML.
  • Inverter Unid. Conversão: Configuração válida para Notas Fiscais de Exportação. Caso a Nota possua uma unidade de conversão informada, o sistema irá inverter os campos qTrib, uTrib, vUnTrib para qCom, uCom, vUnCom no XML de sua Nota Fiscal.
  • Descrição: Descrição do código NCM.

Edição de Cadastro de Ncm/Ibpt

Ao acessar a tela, você conseguirá listar todos os NCM ou filtrá-los de acordo com os filtros disponíveis na tela, para editá-los clique no botão Editar.

Exclusão de Cadastro de Ncm/Ibpt

Você também conseguirá fazer a exclusão de um registro de NCM quando o mesmo não for mais válido ou não for mais utilizá-lo no sistema, clicando em Excluir. Desta forma esse NCM não poderá ser utilizado em nenhuma rotina do sistema. Caso necessário, você poderá restaurar o registro excluído, clicando em Restaurar Registro na lista de Cadastro de Ncm/Ibpt, lembrando que essa opção é exibida apenas para usuários configurados como Administrados.
