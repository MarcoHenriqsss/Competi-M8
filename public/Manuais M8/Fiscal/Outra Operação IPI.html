Outra Operação IPI

A tela Outras Operações IPI visa permitir o cadastro de ajustes de IPI (Imposto sobre Produtos Industrializados) relacionados a operações fiscais que não se enquadram nos lançamentos padrões de entrada ou saída.

Essa funcionalidade é destinada ao registro de operações especiais ou específicas, como:

  • Ajustes manuais de crédito ou débito de IPI;
  • Lançamentos de operações com tratamento diferenciado pelo fisco;
  • Compensações ou ajustes por exigência da legislação tributária.

Segue orientações para cadastro:

Fiscal > MOVIMENTO > APURAÇÃO IPI > Outras Operações

Para adicionar um novo registro de Outras Operação IPI, basta clicar em adicionar e, para caso deseja pesquisar uma operação já cadastrada, informar o método de pesquisa, na aba de pesquisa.

  • Código: Código gerado automaticamente pelo sistema.
  • Data para Apuração: Informar a data de apuração (a data de lançamento desse registro).
  • Operação Fiscal Apuração: Informar nesse campo o tipo de ajuste que vai ser realizado, como Outros Débitos, Outros Créditos por exemplo.
  • Tipo Ajuste: Identificar aqui nesse campo, se esse ajuste é um crédito ou débito.
  • Valor: Colocar nesse campo o valor do imposto que será ajustado.
  • Indicador Origem: Informar neste campo a origem desse ajuste, exemplo se é um processo Judicial, documento fiscal, algo relacionado.
  • Tabela Contábil: Informar a tabela contábil, para contabilização desse valor.
  • Nr Documento/Processo: Informar o número do documento caso for, ou numero do processo caso se trate de algum processo.
  • Observação: Preencher nesse campo, caso houver alguma observação referente este lançamento.

Após preencher todas essas informações, clicar em salvar, para que as informações fiquem gravadas.
