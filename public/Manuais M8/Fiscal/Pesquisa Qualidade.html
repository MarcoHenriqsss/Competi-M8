Pesquisa Qualidade

Essa tela, você enviará email Pesquisa de Qualidade para seus clientes m8. Você pode definir o layout do e-mail que será enviado. Para isso, é necessário configurar um modelo acessando: Workflow > Cadastros > Cadastros > Lista Cadastro de Modelos de Documentos.

CRM > MOVIMENTO > QUALIDADE > Pesquisa Qualidade

  • Modelo de E-mail: Descrever o conteúdo do e-mail que será encaminhado ao cliente. Caso não tiver um modelo de documento, o cadastro desse modelo pode ser realizado através do seguinte caminho: Workflow > Cadastros > Cadastros > Lista Cadastro de Modelos de Documentos. No campo Tipo, deverá ser informado em qual situação o modelo será utilizado, como, por exemplo, para E-mail Marketing ou Pesquisa de Qualidade. Segue abaixo um modelo.

  • Período: Informar o período dos cadastros dos clientes, exemplo caso deseje enviar somente para os clientes cadastrados no mês de junho/2025, selecione o intervalo, se caso deseja para todos informar uma data maior exemplo 01/01/2000 até a data que ira efetuar o envio. Se a intenção for incluir todos os clientes cadastrados, utilize uma data inicial mais ampla, como 01/01/2000, até a data de envio desejada.
  • Cliente: Informar se o envio será direcionado a clientes específicos. Caso a pesquisa deva ser enviada a todos os clientes, este campo deve permanecer em branco, mas precisa clicar em “Pesquisar” que vai listar todos os clientes a baixo da tela, selecionará no cabeçalho o “V”, que selecionará todos os clientes listados.
  • Ramo Econômico: Poderá filtrar os contatos a partir do Ramo Econômico da empresa, informando o ramo neste campo.
  • Atividade Econômica: Especificar a atividade econômica correspondente às empresas que receberão o e- mail.
  • Município: Poderá filtrar os clientes desejados, pelo Municipio de endereço dos clientes.
  • Estado/UF: Poderá filtrar os clientes desejados, pelo Estado de endereço dos clientes.

Após fazer o preenchimento dos dados nos campos obrigatórios e campos adicionais que considerar relevantes, clicar em para prosseguir o email.
