Composição Estrutura de Produtos.

Uma estrutura de produtos é uma organização hierárquica que representa a relação entre diferentes produtos e suas subpartes. Ela descreve como os produtos são compostos e como estão relacionados entre si. A estrutura de produtos geralmente é representada em formato de árvore, onde o produto final está no nível superior e suas subpartes estão nos níveis inferiores. Cada nível da estrutura pode ter várias ramificações, representando as diferentes opções ou variantes disponíveis. Em resumo, uma estrutura de produtos fornece uma visão detalhada da composição e relação entre os produtos, facilitando a gestão, controle e planejamento da produção.

Inclusão de Composição Estrutura de Produtos

Nessa tela, serão listados as estruturas de produtos já criadas nos sistema, para pesquisa-las, basta utilizar dos filtros disponíveis. Para adicionar uma nova Estrutura, basta clicar em.

Cabeçalho

  • Código: Código interno da estrutura, gerado automaticamente pelo sistema.
  • Estabelecimento: Campo disponível para informar o estabelecimento que a estrutura pertence.
  • Produto: Campo disponível para informar o produto final da estrutura.
  • Centro de Custo: Campo disponível para informar o centro de custo da estrutura, para realizar o rateio de custos.
  • Estrutura Similar: Campo disponível para informar uma estrutura similar, essa opção, possibilita a importação de itens da composição similar de outro produto.
  • Depósito: Campo disponível para informar qual o depósito/local estoque do produto final.
  • Versão: Campo disponível para informar a versão da Estrutura do Produto. Campo com digitação liberada, no formato alfanumérico.
  • Revisão: Campo no formato data, para informar a data de revisão da Estrutura.
  • Quantidade: Campo disponível para informar a quantidade do produto final.
  • Lista de Custo: Campo disponível para selecionar qual Custo será considerado para os produtos matéria prima, poderá escolher dentre as opções: Custo Médio, Custo Gerencial ou Manual.
  • Casas Decimais Custo: Campo disponível para parametrizar as casas decimais referente ao custo.
  • Casas Decimais Índice Perda: Campo disponível para parametrizar as casas decimais referente a índice de perda.
  • Casas Decimais Quantidades: Campo disponível para parametrizar as casas decimais referente a quantidade.

Para salvar o cabeçalho da estrutura do produto, basta clicar em.

Itens

  • Código: Código interno do lançamento do item, gerado automaticamente pelo sistema.
  • Tipo: Campo disponível para seleção do tipo de item que será inserido, selecione uma das opções.
    • 1 - Item: Quando selecionado, possibilitará o usuário a lançar um item matéria prima na composição do produto final.
    • 2 - Recurso: Quando selecionado, possibilitará o usuário a lançar um recurso na composição do produto Final, por exemplo, "Água, Energia Elétrica, Estamparia...".
  • 3 - Texto: Quando selecionado, possibilitará o usuário a lançar de forma manual e em formato texto qualquer informação para composição do produto final.
  • 4 - Componente: Quando selecionado, possibilitará ao usuário lançar um produto componente para composição do produto final. Vale ressaltar que o componente é um cadastro de estrutura, então se o produto a ser produzido for um computador e um dos itens é o teclado por exemplo, mas para obter o teclado também é necessário o processo de produção, precisa ser selecionada a estrutura desse teclado ao invés do cadastro de produto dele.
  • 5 - Serviço: Quando selecionado, possibilitará o usuário a lançar um serviço para composição do produto final.
  • Produto/Recurso/Texto/Componente/Serviço: O nome do campo será exibido de acordo com a opção marcada no campo acima, este está disponível para informar o item a ser utilizado na Estrutura..
  • Quantidade: Campo disponível para informar a quantidade do produto matéria prima a ser consumido.
  • Índice de Perda: Campo disponível para informar o índice de perda do produto.
  • Custo Unitário: Campo disponível para informar o custo do produto, considerando a configuração da tela anterior, Custo Médio, Gerencia ou Manual, quando utilizado Custo Médio ou Gerencial, o sistema irá considerar o custo do dia do produto, quando utilizar Manual, ficará a cargo do usuário informar o custo. Caso o item já tenha um valor de custo, o campo será preenchido automaticamente com esse valor.
  • Custo Total: Campo de visualização, o mesmo refere-se ao resultado da multiplicação entre Quantidade x Custo.
  • Gerar Ordem Produção: Quando marcado, o sistema irá considerar o produto para geração de Ordem de Produção.
  • Industrialização de Terceiros: Quando marcado, o sistema considerará a industrialização do produto de forma terceirizada, ou seja, a produção ou industrialização do mesmo passará por outra empresa.
  • Local Estoque Origem: Campo disponível para informar o local de estoque que será feita a saída do estoque da matéria prima.
  • Localização Estoque: Campo aberto para digitar a localização no estoque.
  • Observações: Campo aberto para digitar as observações sobre item.

Para salvar a digitação do item basta clicar em. Dessa forma conseguirá fazer novos lançamentos.

  • Código: Código interno do lançamento da alocação, gerado automaticamente pelo sistema.
  • Tipo Alocação: Campo disponível para informar as alocações dentre as seguintes opções: Energia Elétrica, Funcionário, Manutenção e Terceiro.
  • Custo Total: Campo aberto para informar o custo total da Alocação, o mesmo não soma ao total da estrutura.

Para salvar a digitação da alocação basta clicar em. Dessa forma conseguirá fazer novos lançamentos.

Anexos

A aba Anexos permitirá que você anexe imagens ou arquivos, estes ficarão vinculados a esta Composição de Estrutura. O anexo poderá ser feito a partir da leitura do QR Code, ou anexo direto de arquivos.

  • Códígo: Código interno gerado automaticamente pelo sistema.
  • Fotos pelo Celular: Através da leitura do QR-Code com um Smartphone, o sistema direciona o usuário para um link com esta Composição de Estrutura, onde todos os arquivos e imagens que o usuário incluir por esse link irá aparecer na grid de anexos do Cadastro.
  • Descrição: Campo onde será informado nome para identificação do anexo.
  • Arquivo: Campo onde será possível selecionar o arquivo desejado.

Após preencher os campos, clique em para que o item seja lançado na listagem abaixo, dessa forma você poderá lançar um novo item, assim como editá-los.

Árvore

Na aba árvore, temos a representação do produto, que está no primeiro nível, corresponde ao produto final, resultado da montagem ou composição. A partir dele, ramificam-se os diferentes componentes ou subprodutos que o compõem. Esses componentes podem ser subdivididos em subcomponentes e assim por diante, até alcançar as partes mais básicas e indivisíveis.

FCI

Na aba FCI, temos a informação referente a Ficha de Conteúdo de Importação, a FCI é utilizada para calcular o conteúdo nacional e estrangeiro de um produto, geralmente com o objetivo de determinar benefícios fiscais ou tarifários. Nessa aba são apresentadas quantidades de itens que se enquadram com origem Nacional ou Importada, c om base nisso, você poderá validar se o produto a ser produzido tem uma maior quantidade de itens de um tipo para determinar a origem a ser inserida no seu cadastro.

Setores

Através desta nova opção poderão ser informados os departamentos e serviços envolvidos no processo de produção.

  • Código: Código de identificação interna do setor, gerado automaticamente pelo sistema.
  • Departamento: Informe o departamento desejado.
  • Serviço: Informe o serviço que será executado no departamento informado.
  • Observações: Campo aberto para informações complementares sobre esse cadastro de setor.

Para salvar a digitação do item basta clicar em. Dessa forma conseguirá fazer novos lançamentos.

Ações

  • Copiar Composição: Permite duplicar a estrutura original para uma cópia.
  • Atualizar Custo: Você poderá atualizar essa opção para atualizar o custo dos itens informado, caso os mesmos tenham sofrido algum tipo de alteração.
  • Imprimir Ficha Técnica: Permite a impressão da Ficha Técnica no formato PDF.
  • Imprimir Ficha Técnica XLS: Permite a impressão da Ficha Técnica no formato Excel.
  • Imprimir Árvore: Permite a impressão da Árvore no formato PDF.
  • Imprimir Árvore XLS: Permite a impressão da Árvore no formato Excel.
