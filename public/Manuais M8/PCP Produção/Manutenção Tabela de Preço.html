Manutenção Tabela de Preço

Nessa rotina, poderá realizar manutenções nas tabelas de preço de forma prática e rápida, como atualização de valores de todos os produtos pertinentes a tabela de preço.

Estoque > MOVIMENTO > MOVIMENTO > Manutenção de Produtos

Filtros

  • Campo a Atualizar: Campo onde você selecionará qual o valor será atualizado e qual método utilizado para tal alteração.
    • 0 - Valor[=]: Quando selecionado, o sistema irá atualizar o valor de venda para o valor informado no campo Valor a Atualizar.
    • 1 - Valor[+]: Quando selecionado, o sistema irá somar o valor de venda do produto com o valor informado no campo Valor a Atualizar.
    • 2 - Valor [-]: Quando selecionado, o sistema irá subtrair o valor de venda com o valor informado no campo Valor a Atualizar.
  • 3 - Valor% [+]: Quando selecionado, o sistema irá somar o valor de venda do produto com o valor informado em formato de porcentagem,
    • Exemplo: R$50,00 (Preço de venda) + 5% (Sobre o preço de venda) = R$ 52,50
  • 4 - Valor% [-]: Quando selecionado, o sistema irá subtrair o valor de venda do produto com o valor informado em formato de porcentagem.
    • Exemplo: R$50,00 (Preço de venda) - 5% (Sobre o preço de venda) = R$ 47,50
  • 5 - Valor Mínimo [=]: Quando selecionado, o sistema irá atualizar o valor de venda mínimo para o valor informado no campo Valor a Atualizar.
  • 6 - Valor Mínimo [+]: Quando selecionado, o sistema irá somar o valor de venda mínimo do produto com o valor informado no campo Valor a Atualizar.
  • 7 - Valor Mínimo [-]: Quando selecionado, o sistema irá subtrair o valor de venda mínimo com o valor informado.
  • 8 - Valor Mínimo% [+]: Quando selecionado, o sistema irá somar o valor de venda mínimo do produto com o valor informado em formato de porcentagem.
    • Exemplo: R$50,00 (Valor mínimo) + 5% (Sobre o valor mínimo) = R$ 52,50
  • 9 - Valor Mínimo% [-]: Quando selecionado, o sistema irá subtrair o valor de venda mínimo do produto com o valor informado em formato de porcentagem.
    • Exemplo: R$50,00 (Valor mínimo) - 5% (Sobre o valor mínimo) = R$ 47,50
  • Valor a Atualizar: Campo destinado a informar o valor que será considerado para as atualizações citadas a cima, ou seja, o valor de venda ou venda mínimo do produto.
  • Tipo Atualização: Filtro disponível para selecionar qual será a forma de atualização do preço, no filtro terá as seguintes opções.
    • 0 - Padrão: O sistema usará as regras atuais para atualizar o valor de venda do sistema.
    • 1 - Tabela Preço Base: Quando selecionada, será possível utilizar outra tabela de preço para atualizar os valores de venda.
  • Arredondar Valor Calculado: Filtro disponível para selecionar as casas decimais que serão arredondadas.
  • Tabela Preço: Campo disponível para filtrar a tabela de preço que será atualizada.
  • Código Inicial: Campo disponível para filtrar uma faixa de produtos que serão atualizados.
  • Nome Produto: Campo disponível para filtrar o produto (Nome) que será atualizado, você poderá informar palavras chave presentes no nome de vários produtos, assim todos estes serão exibidos na listagem.
  • Produto/Serviço: Campo disponível para filtrar um produto ou serviço específico (Código) que será atualizado.
  • Fornecedores: Campo disponível para filtrar por um Fornecedor, ou seja, listar todos os Produtos de determinado Fornecedor.
  • Condição de Pagamento: Campo disponível para filtrar as tabelas por condição de pagamento.
  • Grupo Estoque: Campo disponível para filtrar as tabelas por grupo de estoque dos produtos.
  • Família: Campo disponível para filtrar as tabelas por família dos produtos.
  • NCM: Campo disponível para filtrar as tabelas por NCM dos produtos.

Para pesquisar a tabela de preço basta clicar em.

Ao clicar em Pesquisar, o sistema listará os produtos da tabela de preço, conforme imagem acima.

Para Simular o Cálculo da manutenção, basta clicar em. Dessa forma o sistema apenas listará em tela o valor a ser atualizado.

Para atualizar o item, deverá ser selecionado o mesmo através do checkbox, após selecionado o item, basta clicar em, dessa forma o sistema irá atualizar os itens selecionados.
