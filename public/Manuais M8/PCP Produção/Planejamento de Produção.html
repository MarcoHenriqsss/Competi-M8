Planejamento de Produção

Planejamento de produção é uma tela, onde possibilita, inserir todos os dados referente a produção para ficar adequado para o momento da produção. Realizando assim todo o planejamento correto como quantidade produzida, quantidade necessária, qual produto vai ser utilizado, o início da produção, encerramento e inserir o projeto. Vai informar todos os dados necessários para uma produção ser iniciada. Abaixo segue caminho da tela:

PCP Produção > MOVIMENTO > ORDEM DE PRODUÇÃO > Planejamento Produção

Nessa tela para adicionar um novo planejamento clicar no, caso deseja pesquisar um planejamento que já tenha emitido, informar no canto direito superior o código/Tipo de Ordem de produção ou selecionar um dos filtros de pesquisa, após isso clicar na lupa para realizar a pesquisa.

Abaixo segue os descritivos de capa campo. Atenção: Os campos em negritos são obrigatórios, então eles precisa ser preenchidos, campos que não estão em negrito, são campos complementares, a critério de cada empresa a utilização. Alguns desses campos pode se tornar obrigatório caso determinado de alguma empresa, para tornar obrigatório apenas clicar na engrenagem.

  • Código: Código sequencial gerado automaticamente pelo sistema
  • Status: Status gerado automaticamente pelo sistema.
  • Tipo Ordem Produção: Informar o tipo de produção que vai ser produzida, exemplo: Fabricação De Palets
  • Status Fluxo: Informará o status que se encontra esse planejamento de produção. Exemplo: Em andamento, aguardando, finalizado.
  • Produto: Informara o produto que vai ser fabricado.
  • Centro de Custo: Informara o centro de custo que ira utilizar. Exemplo: De qual conta vai consumir esse valor para produção.
  • Estabelecimento: Informará o estabelecimento que vai utilizar.
  • Local Estoque: Informará o local de estoque que vai utilizar nesse planejamento.
  • Usuário: Informará o usuário que emitiu esse planejamento de produção.
  • Pedido: Caso estiver um pedido atrelado, informar nesse plano.
  • Cliente: Caso tiver um cliente específico para esse produto informar aqui.
  • Qtde. Produzida: Informar a quantidade a ser produzida
  • Qtde. Necessária: Informar a quantidade necessária a ser produzida
  • Qtde. Apontamento: Sistema preenche automaticamente partindo das informações informadas nos campos acima.
  • Emissão: Informar data de emissão do planejamento de produção.
  • Início: Informar data de início da emissão da produção.
  • Vencimento: Informar uma data de vencimento para essa produção que poderia ser a mesma data de encerramento ou superior a isso.
  • Encerramento: Informar data de encerramento da produção.
  • Projeto: Caso houver, informará o projeto atrelado a esse planejamento de produção.
  • Etapa: Informara a etapa que consta dentro da produção, caso seja etapa 1, 2 seguindo.
  • Proposta: Caso houver, descreverá uma proposta nesse campo.
  • Observação: Caso tiver alguma descrição a ser mencionada, informar aqui.
