Conferência de Estoque por Projeto

Este processo tem como objetivo realizar uma análise detalhada do estoque dos produtos relacionados às tarefas de um projeto específico. Ele visa proporcionar informações valiosas para a tomada de decisões estratégicas nos âmbitos de Compras, Requisições e Solicitações de Compras. Ao fornecer uma visão abrangente do estado do estoque, este procedimento capacita a equipe a otimizar suas operações, garantindo que as aquisições e solicitações sejam realizadas de maneira eficiente e alinhada aos objetivos do projeto.

Projeto > MOVIMENTO > PROJETOS > Conferência de Estoque por Projeto

Filtros

  • Projeto: Campo disponível para informar o projeto que deseja fazer a pesquisa.
  • Projeto Tarefa: Campo disponível para informar a tarefa de determinado projeto que deseja fazer a pesquisa.
  • Somente com Estoque: Ao marcar, serão listados apenas os itens que possuem estoque no sistema, desconsiderando negativos e zerados.
  • Somente com Sugestão: Ao selecionar essa opção, apenas os itens que requerem compra serão exibidos.

Ações

  • Lançar Ordem de Produção: Permite realizar o lançamento do item selecionado em uma Ordem de Produção, utilizando-o diretamente como item consumido.
  • Lançar Requisição: Permite realizar o lançamento do item selecionado em uma Requisição de Consumo ja lançada no sistema, vinculada a uma ordem de Produção, ao clicar você poderá selecionar a Requisição que deseja inserir tal item.
  • Gerar Nova Requisição: Permite realizar o lançamento do item selecionado a uma nova Requisição de Consumo, vinculada a uma Ordem de Produção.
  • Geração Cotação de Compra: Permite realizar o lançamento do item selecionado uma nova Cotação de Compra.
  • Gerar Solicitação de Compra: Permite realizar o lançamento do item selecionado uma nova Solicitação de Compra.
  • Exportar para (.xls): Permite exportar os itens selecionado em formato XLS.
